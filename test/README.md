# مجلد الاختبارات - Error Tracking System

**المشروع:** بصير MVP  
**التاريخ:** 3 ديسمبر 2025  
**المؤلف:** فريق وكلاء تطوير مشروع بصير

---

## الهيكل

```
test/
├── hooks/              # اختبارات Git Hooks
├── log_collection/     # اختبارات جمع السجلات
├── archive/            # اختبارات الأرشفة
├── security/           # اختبارات الأمان
└── performance/        # اختبارات الأداء
```

## أنواع الاختبارات

### Unit Tests

اختبارات الوحدة للتحقق من وظائف محددة

### Property-Based Tests

اختبارات الخصائص للتحقق من السلوك عبر مدخلات متعددة (100+ iteration)

## تشغيل الاختبارات

```bash
# تشغيل جميع الاختبارات
./test/run_all_tests.sh

# تشغيل اختبارات محددة
./test/run_hooks_tests.sh
./test/run_log_tests.sh
./test/run_archive_tests.sh
```
