# مجلد السجلات - Error Tracking System

**المشروع:** بصير MVP  
**التاريخ:** 3 ديسمبر 2025  
**المؤلف:** فريق وكلاء تطوير مشروع بصير

---

## الهيكل

```
logs/
├── archive/          # السجلات القديمة (أكثر من 7 أيام)
├── errors/           # السجلات التالفة أو الأخطاء الحرجة
└── reports/          # التقارير اليومية الشاملة
```

## الاستخدام

### السجلات الحالية

يتم حفظ السجلات الحالية مباشرة في مجلد `logs/`:

- `flutter_analyze_YYYY-MM-DD_HH-MM-SS.log`
- `flutter_test_YYYY-MM-DD_HH-MM-SS.log`

### الأرشيف

السجلات الأقدم من 7 أيام يتم نقلها تلقائياً إلى `archive/`

### الضغط

عندما يتجاوز حجم الأرشيف 10MB، يتم ضغطه في ملف `archive_YYYY-MM-DD.tar.gz`

### التقارير

التقارير اليومية الشاملة يتم حفظها في `reports/`
