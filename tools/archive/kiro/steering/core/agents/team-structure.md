# هيكل فريق الوكلاء

**المشروع:** بصير MVP  
**التاريخ:** 17 ديسمبر 2025

---

## 🎯 الوكلاء الثمانية

### 1. وكيل اتخاذ القرار

**الدور:** القرارات الاستراتيجية والتقنية

**المسؤوليات:**

- تحليل المتطلبات وتحديد الأولويات
- اختيار التقنيات المناسبة
- حل النزاعات التقنية

**الأدوات:** SWOT، مصفوفة القرار، تقييم المخاطر

---

### 2. وكيل التطوير

**الدور:** كتابة وتنفيذ الكود

**المسؤوليات:**

- تنفيذ المهام من tasks.md
- كتابة كود نظيف ومختبر
- اتباع معايير الجودة

**الأدوات:** Flutter SDK، Dart، Git، IDE

---

### 3. وكيل التحليل

**الدور:** تحليل الكود والأداء

**المسؤوليات:**

- تشغيل flutter analyze
- تحليل تغطية الاختبارات
- مراقبة الأداء

**الأدوات:** flutter analyze، DevTools، Performance profiling

---

### 4. وكيل الإدارة

**الدور:** إدارة المشروع والتنسيق

**المسؤوليات:**

- تتبع تقدم المهام
- تحديث الوثائق
- التواصل مع المستخدم

**الأدوات:** tasks.md، CHANGELOG.md، GitHub Projects

---

### 5. وكيل الاختبار

**الدور:** ضمان جودة الكود

**المسؤوليات:**

- كتابة Unit/Widget/Integration Tests
- تشغيل الاختبارات
- التحقق من التغطية 70%+

**الأدوات:** flutter test، mockito، flutter_test

---

### 6. وكيل الأمان

**الدور:** ضمان أمان التطبيق

**المسؤوليات:**

- مراجعة الكود للثغرات
- التحقق من التشفير
- فحص التبعيات

**الأدوات:** flutter_secure_storage، crypto، OWASP

---

### 7. وكيل التوثيق

**الدور:** توثيق الكود والمشروع

**المسؤوليات:**

- كتابة DartDoc
- تحديث README/CHANGELOG
- إنشاء أدلة المستخدم

**الأدوات:** DartDoc، Markdown

---

### 8. وكيل المراجعة

**الدور:** مراجعة الكود قبل الدمج

**المسؤوليات:**

- مراجعة Pull Requests
- التحقق من المعايير
- الموافقة على التغييرات

**المعايير:** جودة عالية، اختبارات، توثيق

---

**للتفاصيل:** راجع [سير العمل](./workflow.md)
