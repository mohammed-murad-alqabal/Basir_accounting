## 🛠️ الوظائف المتاحة الآن

### **📁 إدارة الملفات:**

- `get_file_contents` - قراءة محتوى الملفات
- `create_or_update_file` - إنشاء أو تحديث الملفات
- `push_files` - رفع ملفات متعددة

### **🔍 البحث والاستكشاف:**

- `search_repositories` - البحث في المستودعات
- `search_code` - البحث في الكود
- `search_issues` - البحث في Issues
- `search_users` - البحث في المستخدمين

### **📋 إدارة Issues:**

- `list_issues` - عرض Issues
- `get_issue` - تفاصيل Issue محدد
- `create_issue` - إنشاء Issue جديد
- `update_issue` - تحديث Issue
- `add_issue_comment` - إضافة تعليق

### **🔀 إدارة Pull Requests:**

- `list_pull_requests` - عرض PRs
- `get_pull_request` - تفاصيل PR محدد
- `create_pull_request` - إنشاء PR جديد
- `get_pull_request_files` - ملفات PR

### **🌿 إدارة الفروع:**

- `create_branch` - إنشاء فرع جديد
- `list_commits` - عرض Commits

### **🍴 عمليات متقدمة:**

- `fork_repository` - نسخ مستودع

## 🔧 استكشاف الأخطاء

### **إذا لم تعمل الوظائف بعد إعادة التشغيل:**

#### **1. تحقق من متغير البيئة:**

```bash
echo "GITHUB_TOKEN length: ${#GITHUB_TOKEN}"
# يجب أن يكون 40 حرف
```

#### **2. اختبر GitHub API مباشرة:**

```bash
curl -H "Authorization: token $GITHUB_TOKEN" https://api.github.com/user
```

#### **3. تحقق من تكوين MCP:**

```bash
cat .kiro/settings/mcp.json | grep -A 20 '"github"'
```

#### **4. أعد تشغيل Kiro مرة أخرى:**

- أغلق Kiro تماماً
- انتظر 10 ثوانِ
- أعد التشغيل
