# نظام التصميم لتطبيق "بصير" (Basir) - الإصدار الأولي

## 1. فلسفة التصميم

يرتكز تصميم "بصير" على مبادئ **الثقة، الوضوح، والبساطة**. يجب أن يشعر المستخدم بالاحترافية والأمان عند التعامل مع بياناته المالية.

*   **الثقة:** تُبنى من خلال استخدام ألوان هادئة وموثوقة (الأزرق الداكن والأخضر)، وتصميم نظيف.
*   **الوضوح:** يُحقق من خلال استخدام خطوط عربية واضحة، ومساحات بيضاء كافية، وتصنيف بصري واضح للبيانات.
*   **البساطة:** تُطبق من خلال تقليل الخطوات اللازمة لإنجاز المهام (مثل إنشاء فاتورة) والتركيز على الوظيفة الأساسية.

## 2. الهوية البصرية

### 2.1. لوحة الألوان (Color Palette)

| الاسم | الكود السداسي (Hex Code) | الاستخدام |
| :--- | :--- | :--- |
| **اللون الأساسي (Primary)** | `#007BFF` (أزرق موثوق) | الأزرار الرئيسية، الأيقونات النشطة، رؤوس الصفحات. يعكس الثقة والاحترافية. |
| **اللون الثانوي (Secondary)** | `#28A745` (أخضر نجاح) | مؤشرات النجاح، الفواتير المدفوعة، أزرار الإضافة (CTA). يعكس النمو والمال. |
| **لون الخلفية (Background)** | `#F8F9FA` (رمادي فاتح جدًا) | خلفية الشاشات الرئيسية لتقليل إجهاد العين وإبراز المحتوى. |
| **لون النص الأساسي (Text Primary)** | `#212529` (أسود داكن) | النصوص الرئيسية والعناوين. |
| **لون النص الثانوي (Text Secondary)** | `#6C757D` (رمادي متوسط) | النصوص المساعدة، التواريخ، وحالة الفواتير غير النشطة. |
| **لون التحذير/الخطأ (Danger)** | `#DC3545` (أحمر) | الفواتير المستحقة، رسائل الخطأ. |

### 2.2. الخطوط (AppTypography.

سيتم اختيار خطوط عربية وإنجليزية مفتوحة المصدر وواضحة لضمان أفضل قراءة على شاشات الموبايل.

*   **الخط العربي:** سيتم استخدام خط **"Tajawal"** أو **"Cairo"** (سيتم تأكيد الأفضلية بعد تجربة التنفيذ) لكونهما خطوطًا حديثة، واضحة، وتدعم الأوزان المختلفة بشكل ممتاز في تطبيقات الموبايل.
*   **الخط الإنجليزي:** سيتم استخدام خط **"Roboto"** (الخط الافتراضي لـ Material Design) لضمان التناسق مع نظام التشغيل.

### 2.3. الأيقونات (Icons)

سيتم الاعتماد على مكتبة **Material Icons** من Google، مع التركيز على الأيقونات ذات النمط الخطي (Outlined) للحفاظ على مظهر نظيف وحديث.

## 3. المكونات الأساسية (Core Components)

| المكون | الوصف | المظهر |
| :--- | :--- | :--- |
| **الأزرار الرئيسية (Primary Button)** | خلفية باللون الأساسي (`#007BFF`)، نص أبيض، حواف دائرية خفيفة. | يعكس الإجراء الأكثر أهمية في الشاشة. |
| **حقول الإدخال (Text Fields)** | تصميم "مملوء" (Filled) أو "مخطط" (Outlined) بخلفية بيضاء وحواف دائرية. يجب أن تدعم اتجاه الكتابة من اليمين لليسار (RTL) بشكل كامل. | يجب أن تكون واضحة ومريحة للإدخال الطويل للأرقام والنصوص. |
| **البطاقات (Cards)** | خلفية بيضاء، ظل خفيف جدًا (Elevation)، وحواف دائرية. تستخدم لتجميع المعلومات ذات الصلة (مثل تفاصيل الفاتورة أو العميل). | تستخدم لتنظيم المحتوى في لوحة التحكم وقوائم الفواتير. |
| **شريط التنقل السفلي (Bottom Navigation Bar)** | تصميم بسيط وواضح، بأيقونات نصية أسفلها، يستخدم للوصول السريع إلى الأقسام الرئيسية (لوحة التحكم، الفواتير، العملاء، الإعدادات). | يجب أن يكون ثابتًا ومرئيًا دائمًا. |
