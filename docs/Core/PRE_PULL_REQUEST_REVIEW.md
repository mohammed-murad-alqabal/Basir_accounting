# مراجعة ما قبل طلب السحب — حدود سلطة دفتر الأستاذ

**تاريخ المراجعة:** 13 أغسطس 2026
**نطاق الرقعة:** إزالة ازدواجية مصدر الحقيقة بين Isar وPostgreSQL في القيود المنشورة.

## خصائص مثبتة

| الخاصية | آلية الإثبات |
|---|---|
| لا نشر محلي نهائي | `LedgerAuthorityPolicy` وrepository cache-only؛ اختبارات الفاتورة والخزانة تتحقق من عدم استدعاء `addJournalEntry`. |
| Postgres مصدر السلطة | `SupabaseLedgerGateway` لا يكتب Isar قبل receipt؛ cache يحمل `authoritativeEntryId`. |
| idempotency | UUID v5 حتمي في العميل، `p_entry_id` وhash حمولة في RPC، واختبار SQL يعيد العملية ذاتها ثم يرفض تعارض الحمولة. |
| الذرية والاتزان | RPC يتحقق ويكتب الرأس والسطور والتدقيق داخل معاملة واحدة؛ بوابة SQL نجحت في قاعدة نظيفة. |
| التفويض | claims JWT ودور محاسبي في `SECURITY DEFINER`؛ اختبار RPC يتحقق من الرفض عند غياب الدور. |
| فشل النقل | فقط `LedgerTransportException` ينتج outbox؛ رفض Postgres لا يُخفى كنجاح أو إعادة محاولة عمياء. |
| منع LWW | `SyncService` لا يزامن journal entries، ويستدعي تفريغ outbox فقط. |

## قيود معروفة قبل الدمج والإطلاق

1. **لا يصح إطلاق الترحيل مباشرة إلى الإنتاج.** يطبق أولًا على قاعدة staging مع نسخ احتياطي وخطة التراجع والقيد العكسي.
2. **لم تُشغّل حزمة Flutter الكاملة في هذه الجولة.** تظل بوابة المسار المستهدف وCI الجديد هما دليل الرقعة؛ تاريخيًا احتوت الحزمة الكاملة على إخفاقات Supabase initialization غير مرتبطة. يجب إغلاقها منفصلًا أو تأكيد baseline من CI.
3. **فحص Rust غير مكتمل بسبب بيئة الأدوات، لا بسبب خطأ تجميع مثبت.** يجب أن تنفذ CI Rust الحديثة `cargo fmt --check` و`SQLX_OFFLINE=true cargo check -p accounting_data` أو اختبار التكامل مع `DATABASE_URL` قبل نشر الثنائي.
4. **ينبغي إدراج المسار الجديد في قواعد حماية فرع `main`** حتى لا يبقى CI مجرد workflow غير إلزامي.

## خطوات ما بعد دمج آمنة

1. تطبيق ترحيل RPC على staging من مسار الترحيلات المعتمد.
2. تشغيل `scripts/ledger_health_check.sql` وتصدير تقرير `scripts/reconcile_ledger.py` في وضع القراءة فقط.
3. تجربة نشر وإعادة محاولة وانقطاع شبكة وتضارب operation في staging بحسابات وأدوار حقيقية.
4. مراجعة محاسب مخول، ثم نافذة نشر إنتاجية مع مراقبة مؤشرات الصحة والمصالحة.
