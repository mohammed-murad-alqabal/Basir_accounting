# تقرير تنفيذ اختبارات UI/UX — بصير المحاسبي

**التاريخ:** 2026-08-23
**النطاق:** الدفعة الأولى من تنفيذ خطة الاختبار الشاملة

## الملخص التنفيذي

تم تحويل الجزء الأعلى أولوية من خطة UI/UX إلى أتمتة قابلة للتشغيل. تغطي الدفعة الحالية سلوك `BasirAppShell` والتنقل الجانبي والاستجابة، حالات الوصولية الأساسية، فتح `Omnibar` وتنفيذ نتائجه، وسيناريوهات Golden للشريط العلوي بالعربية في سطح المكتب والعرض المضغوط.

تم إعداد workflow مستقل باسم `Basir UI/UX Regression` ليعمل على Pull Requests والتغييرات الرئيسية ذات الصلة. يعيد workflow استخدام إعداد Flutter المعتمد في المشروع، ويتحقق من المصادر المولدة والتنسيق والتحليل ثم يشغّل اختبارات UI/UX المركزة، ويرفع لقطات الفشل عند الحاجة. بقي دفع ملف workflow إلى GitHub معلّقًا لأن رمز الوصول الحالي لا يملك صلاحية `workflows` اللازمة لإنشاء أو تحديث ملفات GitHub Actions؛ الملف محفوظ ومرفق للتفعيل بعد منح الصلاحية المناسبة.

## ما تم تنفيذه

| المجال | التنفيذ |
|---|---|
| AppShell | اختبارات حدود الاستجابة، الوحدات الثماني، التنقل، الطي، وحفظ دلالة الحالة النشطة |
| Topbar | اختبارات شرائح المؤسسة والفرع والفترة، البحث، الإشعارات، والانتقال بين أحجام العرض |
| Sidebar | اختبارات التنقل، الحالة النشطة، العرض المطوي، وSemantics للتسميات المخفية بصريًا |
| Omnibar | Golden/Widget coverage لفتح الاقتراحات، تنفيذ الأوامر، والنتائج الفارغة |
| Golden | لقطتا سطح مكتب وعرض مضغوط بالعربية مع RTL وAppTheme وتهيئة Cairo قبل الرسم |
| CI | Workflow مركز مع فحص format وanalyze وbuild_runner واختبارات UI/UX ورفع artifacts عند الفشل |

## نتائج التحقق المحلي

تم تشغيل الأمر التالي بنجاح باستخدام Flutter 3.35.5:

```bash
flutter analyze --fatal-infos \
  lib/core/theme lib/features/navigation lib/shared/widgets \
  test/golden test/unit/shared/widgets test/widget/features/navigation
```

النتيجة: **لا توجد ملاحظات تحليلية**.

وتم تشغيل الاختبارات المركزة التالية بنجاح:

```bash
flutter test --concurrency=1 --reporter expanded \
  test/unit/shared/widgets/app_shell_test.dart \
  test/golden/basir_topbar_golden_test.dart \
  test/widget/features/navigation/presentation/widgets/omnibar_test.dart
```

النتيجة: **27 اختبارًا ناجحًا**.

## ملاحظة المراجعة البصرية

تم فحص Golden baselines بعد توليدها. الاختبار البكسلي يمر، لكن معاينة الصور في عارض بيئة العمل تُظهر glyphs العربية كمربعات؛ لذلك لم تُعتبر المعاينة وحدها دليلًا نهائيًا على صلاحية عرض الخط. المشروع يحتوي Cairo ضمن `assets/fonts/`، وتمت تهيئته قبل الاختبارات. يلزم اعتماد المراجعة البشرية النهائية من artifact صادر عن CI أو جهاز يدعم عرض Cairo قبل اعتبار baseline مرجعًا بصريًا نهائيًا.

## الخطوات التالية

تتضمن الدفعة التالية إضافة رحلات تكامل للمصادقة وإنشاء الفاتورة والمخزون والتقارير، وربط فحوص الوصولية بمقاييس أكثر صرامة مثل حجم هدف اللمس، ترتيب التركيز، والتباين. كما ينبغي حفظ لقطات CI الفاشلة كـ artifacts ومراجعتها بصريًا ضمن عملية Pull Request.
