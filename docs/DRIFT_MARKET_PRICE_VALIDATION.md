# نتيجة تحقق شريحة أسعار السوق في Drift

**الحالة:** مكتملة محليًا؛ لا يوجد commit أو push لهذه الشريحة بعد.

## النطاق المنفذ

أضيف جدول `market_prices` وDAO `MarketPriceStore` إلى حزمة `basir_drift_storage`. وتحتوي الترقية على `schemaVersion = 2` ومسار `from < 2` لإنشاء الجدول فقط. أضيف `DriftMarketPriceRepository` كمكيّف تجريبي، من دون تسجيله في providers؛ يظل `MarketPriceRepositoryImpl` المعتمد على Isar التنفيذ النشط.

| عقد Isar | تحقق Drift |
|---|---|
| upsert بالمعرف | اختبار سجل واحد واستبداله ناجح |
| أحدث سعر ضمن تاريخ شامل | اختبار `as_of_date <= requestedDate` ناجح |
| تاريخ سعر الصنف تنازليًا | اختبار ترتيب السجل الزمني ناجح |
| أحدث سعر لكل صنف | اختبار استبعاد المستقبل واختيار سجل واحد لكل صنف ناجح |
| تعادل التاريخ | ترتيب إضافي حتمي بـ`created_at` ثم `id` مغطى بالاختبار |

## حدود السلامة

لا يتم ترحيل بيانات فعلية أو تشغيل dual-write أو تعديل Supabase أو حذف `MarketPriceModel` أو مولده. قبل القطع الفعلي يلزم استيراد قابل للاستئناف، مقارنة صفوف/تجزئات لكل صنف، وتبديل provider خلف feature flag ثم فترة مراقبة وrollback.
