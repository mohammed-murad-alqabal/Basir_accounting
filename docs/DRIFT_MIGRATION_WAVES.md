# موجات ترحيل Isar إلى Drift

## أسس الترتيب

رُتبت الشرائح وفق حجم العقد، والعلاقات، وحساسية القيود المحاسبية، والتزامن، وإمكان اختبار التكافؤ دون تفعيل تنفيذ Drift في التطبيق. لا يعني ترتيب الموجات جاهزية القطع؛ يبقى Isar المسار النشط حتى تحقق بوابات كل موجة.

| الموجة | الشريحة | المخاطر | سبب الترتيب |
|---|---|---:|---|
| 0 | `BarcodeConfig` | مكتملة تجريبيًا | إعداد منفرد بلا علاقة أو مزامنة نشطة |
| 1 | `MarketPrice` | منخفضة | خمسة حقول، سجل زمني إضافي فقط، وعقد استعلام واضح ومحدود |
| 2 | `Profile` ثم `BusinessSettings` | متوسطة | مقيدة بالمستخدم وتدخل في مسار مزامنة Supabase |
| 3 | Goals وBudgets | متوسطة | مستودعات قائمة وسياق مالي يحتاج اختبارات قيود وتواريخ |
| 4 | Customers, Vendors, Assets, Inventory | مرتفعة | علاقات ومخزون وحركة عبر نماذج متعددة |
| 5 | Invoices, Vouchers, Journal Entries, Financial Years | حرجة | قيد مزدوج، ترحيل، تدقيق، وضرورات عدم التعديل الصامت |
| 6 | إزالة Isar | نهائية | لا تبدأ قبل تكافؤ البيانات والـWeb وسيناريو rollback مثبت |

## اختيار الشريحة الثانية: `MarketPrice`

يطبق مستودع Isar الحالي أربع عمليات فقط: إضافة سجل، تاريخ صنف مرتب تنازليًا، أحدث سعر لا يتجاوز تاريخًا، وأحدث سعر لكل صنف حتى تاريخ مرجعي. لا توجد علاقة Isar مادية أو provider مسجل لهذا المستودع، كما أن الكيان يملك UUID مستقرًا وتاريخين محددين. لذلك يمكن تمثيله بجدول Drift وفهارس صريحة، واختبار منطق «الأحدث حتى تاريخ» ضد SQLite دون تبديل أي تنفيذ فعلي.

## عقد التكافؤ المطلوب

1. يبقى السعر سجلًا زمنيًا غير قابل للكتابة فوق سجل أقدم إلا إذا تطابق `id` نفسه.
2. يستعمل `getLatestPrice` حدًا شاملاً: `as_of_date <= requestedDate`.
3. يعيد `getPriceHistory` السجلات تنازليًا بحسب `as_of_date`.
4. يعيد `getPricesForDate` سجلًا واحدًا لكل `itemId`، هو الأعلى تاريخًا ضمن الحد الشامل.
5. تضيف اختبارات الحالات المتساوية زمنيًا ترتيبًا حتميًا إضافيًا بـ`created_at DESC, id DESC`، حتى لا يتغير السلوك بين المحركات.

## خارج نطاق هذه الموجة

لا يُبدَّل `MarketPriceRepositoryImpl` في providers، ولا يُحذف `MarketPriceModel` أو مولده، ولا يُرحَّل أي سجل بيانات فعلي أو Supabase payload. يقتصر العمل على DAO محايد في الحزمة ومكيّف Domain تجريبي واختبارات التكافؤ.
