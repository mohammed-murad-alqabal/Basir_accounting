# الأدلة والإرشادات

## نظرة عامة

هذا المجلد يحتوي على الأدلة والإرشادات العملية لمشروع بصير MVP، مصنفة حسب المجال والاستخدام.

## المجلدات الفرعية

### 💻 **development/**
أدلة التطوير تشمل:
- إرشادات Git وGitHub
- أطر عمل التطوير
- أفضل الممارسات البرمجية

### 🎨 **design/**
أدلة التصميم تشمل:
- استخدام Figma
- نظام الهوية البصرية
- إرشادات التصميم

### 🔧 **troubleshooting/**
أدلة استكشاف الأخطاء تشمل:
- حل المشاكل التقنية
- تتبع الأخطاء
- مراجعة الأنظمة

## كيفية الاستخدام

### للمطورين الجدد
1. ابدأ بـ `development/` للإرشادات الأساسية
2. راجع `troubleshooting/` عند مواجهة مشاكل

### للمصممين
1. راجع `design/` لإرشادات Figma والهوية البصرية
2. اتبع المعايير المحددة في الأدلة

### للفريق التقني
1. استخدم `troubleshooting/` لحل المشاكل
2. راجع `development/` للممارسات المتقدمة

## إرشادات الصيانة

- تحديث الأدلة عند تغيير العمليات
- إضافة أمثلة عملية جديدة
- مراجعة دورية للتأكد من الدقة
