## 🔧 خوادم تحتاج تكوين (اختياري)

### 1. GitHub (موصى به)

**الفائدة:** إدارة Issues و Pull Requests

**الخطوات:**

```bash
# 1. احصل على Token من GitHub
# اذهب إلى: Settings → Developer settings → Personal access tokens → Generate new token
# اختر صلاحيات: repo, read:org

# 2. أضف Token للبيئة
echo 'export GITHUB_TOKEN="ghp_your_token_here"' >> ~/.bashrc
source ~/.bashrc

# 3. فعّل الخادم
# افتح ~/.kiro/settings/mcp.json
# ابحث عن "github" وغيّر "disabled": true إلى "disabled": false
```

### 2. Brave Search (اختياري)

**الفائدة:** بحث متقدم في الإنترنت

**الخطوات:**

```bash
# 1. احصل على API Key من
# https://brave.com/search/api/

# 2. أضف Key للبيئة
echo 'export BRAVE_API_KEY="your_key_here"' >> ~/.bashrc
source ~/.bashrc

# 3. فعّل الخادم في mcp.json
```

## 🔍 التحقق من التكوين

### تحقق من الخوادم النشطة

```bash
# افتح ملف التكوين
cat ~/.kiro/settings/mcp.json | grep -A 3 '"disabled": false'
```

### تحقق من المتغيرات

```bash
# تحقق من GitHub Token
echo $GITHUB_TOKEN

# تحقق من Brave API Key
echo $BRAVE_API_KEY
```

## 🆘 حل المشاكل

### المشكلة: الخادم لا يعمل

**الحل:**

1. أعد تشغيل Kiro
2. تحقق من السجلات: `~/.kiro/logs/mcp.log`
3. تأكد من تثبيت الأدوات: `uvx --version`, `npx --version`

### المشكلة: Token غير صحيح

**الحل:**

```bash
# أعد تحميل البيئة
source ~/.bashrc

# تحقق من القيمة
echo $GITHUB_TOKEN
```

### المشكلة: رسالة خطأ "Invalid URL"

**الحل:**

- هذا يعني أن الخادم معطل بالفعل
- لا تقلق، الخوادم المعطلة لن تؤثر على العمل
