## 🔴 الخوادم المعطلة (تحتاج تكوين)

### 1. github

- **السبب:** يحتاج GitHub Personal Access Token
- **التكوين المطلوب:**
  ```bash
  export GITHUB_TOKEN="your_token_here"
  ```
- **الأولوية:** متوسطة
- **الفائدة:** إدارة Issues و PRs

### 2. brave-search

- **السبب:** يحتاج Brave API Key

  ```bash
  export BRAVE_API_KEY="your_key_here"
  ```

- **الفائدة:** بحث متقدم في الإنترنت

## 📝 كيفية تفعيل الخوادم المعطلة

### تفعيل GitHub

1. اذهب إلى GitHub Settings → Developer settings → Personal access tokens
2. أنشئ token جديد مع الصلاحيات:
   - `repo` (للوصول للمستودعات)
   - `read:org` (لقراءة المؤسسات)
3. أضف Token للبيئة:
   ```bash
   echo 'export GITHUB_TOKEN="your_token"' >> ~/.bashrc
   source ~/.bashrc
   ```
4. فعّل الخادم في mcp.json:
   ```json
   "github": {
     "disabled": false
   }
   ```

### تفعيل Brave Search

1. اذهب إلى https://brave.com/search/api/
2. سجّل للحصول على API key
3. أضف Key للبيئة:
   ```bash
   echo 'export BRAVE_API_KEY="your_key"' >> ~/.bashrc
   source ~/.bashrc
   ```
4. فعّل الخادم في mcp.json

## 🔐 الأمان

### أفضل الممارسات

1. **لا تخزن Tokens في الكود**

   - استخدم متغيرات البيئة
   - أضف `.env` إلى `.gitignore`

2. **راجع الصلاحيات**

   - أعط أقل الصلاحيات المطلوبة
   - راجع Tokens دورياً

3. **احذف Tokens غير المستخدمة**
   - نظف Tokens القديمة
   - استخدم Tokens محدودة الوقت
