## Success Metrics Framework

This document defines the key metrics that will measure Basir's success from MVP through growth phases. Metrics are organized using the AARRR (Pirate Metrics) framework plus financial and operational indicators.

---

## North Star Metric

> **"Monthly Active Invoices Created"**

**Why This Metric:**

- Directly reflects product value delivered
- Correlates with user engagement
- Leads indicator for revenue
- Measurable, actionable, auditable

**Targets:**
| Phase | Target |
|-------|--------|
| MVP (M3) | 500 invoices/month |
| Launch (M6) | 5,000 invoices/month |
| Year 1 | 50,000 invoices/month |
| Year 2 | 500,000 invoices/month |

## AARRR Metrics Framework

### 1. Acquisition Metrics

| Metric           | Definition                     | Target        | Frequency |
| ---------------- | ------------------------------ | ------------- | --------- |
| App Downloads    | Total installs (iOS + Android) | 10K/mo by M6  | Weekly    |
| Website Visitors | Unique visitors to basir.io   | 50K/mo        | Daily     |
| Sign-up Rate     | Visitors → Sign-ups            | > 5%          | Weekly    |
| CAC              | Cost per acquired user         | < $20         | Monthly   |
| Channel Mix      | % from each channel            | Organic > 40% | Monthly   |

### 2. Activation Metrics

| Metric                | Definition              | Target      | Frequency |
| --------------------- | ----------------------- | ----------- | --------- |
| Onboarding Completion | % completing setup      | > 70%       | Daily     |
| Time to First Invoice | Minutes from signup     | < 5 min     | Weekly    |
| First-Week Engagement | Actions in first 7 days | > 5 actions | Weekly    |
| Feature Adoption      | % using core features   | > 60%       | Weekly    |
| Activation Rate       | Sign-up → Active user   | > 50%       | Weekly    |

### 3. Retention Metrics

| Metric           | Definition              | Target | Frequency |
| ---------------- | ----------------------- | ------ | --------- |
| Day 1 Retention  | % returning next day    | > 50%  | Daily     |
| Day 7 Retention  | % returning after week  | > 40%  | Weekly    |
| Day 30 Retention | % returning after month | > 30%  | Monthly   |
| DAU/MAU Ratio    | Daily/Monthly active    | > 20%  | Weekly    |
| Churn Rate       | % subscribers canceling | < 5%   | Monthly   |

### 4. Revenue Metrics

| Metric          | Definition                | Target      | Frequency |
| --------------- | ------------------------- | ----------- | --------- |
| MRR             | Monthly Recurring Revenue | $100K by Y1 | Monthly   |
| ARR             | Annual Recurring Revenue  | $1M by Y2   | Quarterly |
| Conversion Rate | Free → Paid               | > 10%       | Monthly   |
| ARPU            | Avg Revenue Per User      | > $25/mo    | Monthly   |
| LTV             | Lifetime Value            | > $300      | Quarterly |
| LTV:CAC Ratio   | Value vs Acquisition Cost | > 3:1       | Quarterly |

### 5. Referral Metrics

| Metric            | Definition         | Target | Frequency |
| ----------------- | ------------------ | ------ | --------- |
| Referral Rate     | % users who refer  | > 15%  | Monthly   |
| Viral Coefficient | New users per user | > 0.5  | Monthly   |
| NPS               | Net Promoter Score | > 50   | Quarterly |
| Reviews/Ratings   | App store rating   | > 4.5  | Weekly    |
| Social Shares     | Content shares     | Growth | Weekly    |

## Success Definition

### What Success Looks Like at Each Phase

**MVP Success:**

- 100 active beta users
- Core features working
- Positive user feedback
- No critical issues

**Launch Success:**

- 5,000 users, 250 paying
- Stable product
- Growing organically
- Unit economics positive

**Growth Success:**

- 30,000 users
- $45K MRR
- Strong retention
- Referral engine working

**Scale Success:**

- Market leader in Saudi
- Expanding regionally
- Profitable or funded
- Strong team
