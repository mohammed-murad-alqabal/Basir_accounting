## 7. Escalation Process

### Escalation Path

```
Tier 1 Agent
     │
     │ Cannot resolve after 30 min
     ▼
Tier 2 Specialist
     │
     │ Technical issue / Bug
     ▼
Engineering (via Jira)
     │
     │ Critical / Security
     ▼
Leadership Team
```

### Escalation Criteria

| To          | When                            |
| ----------- | ------------------------------- |
| Tier 2      | Complex billing, ZATCA issues   |
| Engineering | Confirmed bugs, data issues     |
| Leadership  | Security, legal, angry customer |
