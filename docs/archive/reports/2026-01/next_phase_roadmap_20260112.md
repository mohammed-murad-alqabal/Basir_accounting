#### 4.3 إعداد متاجر التطبيقات ⏳

**المدة المقدرة:** 5-7 أيام

**Google Play Store:**

1. **إعداد حساب المطور**

   - تسجيل حساب Google Play Console
   - دفع رسوم التسجيل ($25)
   - التحقق من الهوية

2. **تحضير مواد النشر**

   ```
   - أيقونة التطبيق (512x512)
   - لقطات شاشة (8 لقطات)
   - وصف التطبيق (عربي/إنجليزي)
   - سياسة الخصوصية
   - شروط الاستخدام
   ```

3. **إعداد التطبيق للنشر**

   ```bash
   # بناء النسخة النهائية
   flutter build appbundle --release

   # التوقيع الرقمي
   jarsigner -verify app-release.aab

   # اختبار النسخة النهائية
   bundletool build-apks --bundle=app-release.aab
   ```

**Apple App Store:**

1. **إعداد حساب المطور**

   - تسجيل Apple Developer Account ($99/year)
   - إعداد Certificates & Provisioning Profiles
   - إعداد App Store Connect

2. **تحضير مواد النشر**

   ```
   - أيقونة التطبيق (1024x1024)
   - لقطات شاشة لجميع الأحجام
   - وصف التطبيق (عربي/إنجليزي)
   - معلومات التطبيق والفئة
   ```

3. **بناء وتحميل التطبيق**

   ```bash
   # بناء النسخة النهائية
   flutter build ios --release

   # أرشفة التطبيق
   xcodebuild archive -workspace Runner.xcworkspace

   # تحميل إلى App Store Connect
   xcodebuild -exportArchive
   ```
