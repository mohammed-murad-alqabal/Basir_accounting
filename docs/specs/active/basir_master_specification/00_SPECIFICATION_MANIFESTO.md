## 2. Engineering Principles

### 2.1 Implicit Robustness

The system prevents errors **by design**, not by warning.

- **Barcode Engine** (Screen 024): Implies a normalized, unique SKU database.
- **Balance Sheet** (Screen 057): Implies a real-time aggregation engine.
- **Cash Reconciliation** (Screen 069): Implies self-healing ledger capabilities.

### 2.2 Universal Standards Compliance

| Standard              | Implementation                                                      |
| --------------------- | ------------------------------------------------------------------- |
| **IFRS 18**           | Mandatory classification of Operating, Investing, Financing entries |
| **ZATCA Phase 2**     | CSR generation, XML signing, live reporting simulation              |
| **Sharia Compliance** | Automated Zakat calculation and Riba/Interest flagging              |
| **Saudi Labor Law**   | GOSI contribution tiers embedded                                    |

### 2.3 The Diamond Standard

All code adheres to these non-negotiable constraints:

1. **Zero Lints**: `flutter analyze` and `cargo clippy` must report no issues.
2. **Strict Decimal**: All financial values use `Decimal` (never `double`).
3. **Immutable Ledger**: Posted entries cannot be deleted, only reversed.
4. **Forensic Trail**: Every mutation is cryptographically linked.
