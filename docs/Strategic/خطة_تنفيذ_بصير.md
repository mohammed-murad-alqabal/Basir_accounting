## 5. معايير العمل الإلزامية لكل مهمة

1. **TDD**: اختبارات وحدة + ودجت قبل/مع الكود؛ لا يُدمج ما يخفض التغطية. `flutter test` أخضر كامل + `flutter analyze --fatal-infos`.
2. **العقود موحدة**: القرارات عالية الأثر (ترحيل، تعديل مخزون، ضريبة) تمر عبر طبقة خدمات تعيد `OperationResult` قابلة للاختبار؛ العرض يستقبل قواعد صالحة من طبقة الخدمات ولا يقرر سياسة بنفسه.
3. **التعريب مزدوج AR/EN** مع مولد l10n، RTL ذكي، Semantics، TouchTargets.minimum (44).
4. **الحركات وظيفية**: 150–200ms تمريرات، 200–280ms حوارات، احترام تفضيل تقليل الحركة، Skeleton loading، حفظ داخل الزر بحالة تحميل ثم إشعار ناجح قابل للتراجع.
5. **توثيق عربي بتعليقات `///`**، ورسائل commit/PR بمنهجية conventional commits، وPR منفصل لكل مهمة مع توثيق الإنجاز.
6. **قيود CI**: GitHub Actions محظور حاليًا بسياسة تثبيت SHA على مستوى الحساب — التحقق يتم محليًا، وإصلاح CI لاحقًا (ثبات SHAs).
