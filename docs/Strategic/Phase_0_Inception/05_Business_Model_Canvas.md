## Detailed Canvas Components

### 1. Customer Segments

| Segment         | Size  | Priority | Characteristics                            |
| --------------- | ----- | -------- | ------------------------------------------ |
| **Individuals** | 200M+ | P2       | Tech-savvy Arabs seeking financial control |
| **Freelancers** | 2M+   | P0       | Need invoicing, expense tracking, tax help |
| **SMEs**        | 5M+   | P0       | 1-50 employees, compliance-driven          |
| **Enterprises** | 100K+ | P3       | 50+ employees, need integrations           |

**Primary Focus (MVP):** Freelancers & SMEs in Saudi Arabia

### 2. Value Propositions

| Segment     | Primary Value           | Secondary Values   |
| ----------- | ----------------------- | ------------------ |
