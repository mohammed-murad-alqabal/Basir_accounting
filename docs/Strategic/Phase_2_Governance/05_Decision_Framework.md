## Decision Framework

### Decision Categories

| Category        | Examples                 | Authority        | Timeline  |
| --------------- | ------------------------ | ---------------- | --------- |
| **Strategic**   | Market entry, funding    | Board/Leadership | 1-2 weeks |
| **Product**     | Features, prioritization | Product Lead     | 2-5 days  |
| **Technical**   | Architecture, tools      | Technical Lead   | 1-3 days  |
| **Operational** | Process, workflows       | Team Leads       | 1-2 days  |
| **Tactical**    | Implementation details   | Individual       | Immediate |

## Decision Authority Matrix

| Decision          | Individual | Team Lead | Project Lead | Board |
| ----------------- | ---------- | --------- | ------------ | ----- |
| Bug fix approach  | ✅         | -         | -            | -     |
| Library selection | -          | ✅        | -            | -     |
| Feature priority  | -          | -         | ✅           | -     |
| Hiring            | -          | -         | ✅/✓         | ✓     |
| Major investment  | -          | -         | -            | ✅    |

✅ = Decision maker, ✓ = Approval required

## Decision Process

### Standard Process (RAPID)

| Role          | Responsibility        |
| ------------- | --------------------- |
| **R**ecommend | Proposes decision     |
| **A**gree     | Must agree to proceed |
| **P**erform   | Implements decision   |
| **I**nput     | Provides information  |
| **D**ecide    | Makes final call      |

### Decision Template

```markdown
## Decision: [Title]

**Date:** [Date]
**Status:** [Proposed/Approved/Rejected]

### Context

[Background information]

### Options

1. Option A: [Description]
2. Option B: [Description]

### Recommendation

[Recommended option with rationale]

### Decision

[Final decision and date]

### Outcome

[Results after implementation]
```
