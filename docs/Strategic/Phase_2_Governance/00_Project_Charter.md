## Project Purpose

### Vision

To become the leading intelligent financial operating system for the Arab world.

### Mission

To deliver an intuitive, intelligent, and compliant financial platform that simplifies money management for Arabic-speaking individuals and businesses.

### Business Objectives

| Objective    | Measure             | Target           |
| ------------ | ------------------- | ---------------- |
| Market Entry | Users acquired      | 5,000 by Q2 2026 |
| Revenue      | MRR generated       | $15K by Q4 2026  |
| Compliance   | ZATCA certification | 100%             |
| Satisfaction | NPS score           | > 50             |

## Project Scope

### In Scope (MVP)

| Category           | Features                                                |
| ------------------ | ------------------------------------------------------- |
| **Authentication** | Email/password, social login, MFA                       |
| **Business Mode**  | Invoice creation, customer management, expense tracking |
| **Personal Mode**  | Budget tracking, expense categorization                 |
| **Compliance**     | ZATCA Phase 2, UAE VAT ready                            |
| **AI Features**    | Auto-categorization, OCR receipts                       |
| **Localization**   | Arabic RTL, multi-currency                              |
| **Platform**       | iOS, Android, Web                                       |

### Out of Scope (Post-MVP)

| Feature                  | Timeline |
| ------------------------ | -------- |
| Open Banking integration | Q3 2026+ |
| Payroll management       | 2027     |
| Enterprise multi-tenant  | 2027     |
| API marketplace          | 2028     |
