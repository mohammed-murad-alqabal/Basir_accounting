## 🚀 خطوات التنفيذ السريعة

### الطريقة 1: تنفيذ تلقائي (موصى به)

```bash
# تنفيذ جميع التحسينات بأمر واحد
./scripts/apply_optimizations.sh
```

**الوقت:** 5-10 دقائق  
**الصعوبة:** سهل جداً

### الطريقة 2: تنفيذ يدوي

```bash
# 1. تنظيف build
flutter clean

# 2. إنشاء gradle.properties
mkdir -p ~/.gradle
cp gradle.properties.template ~/.gradle/gradle.properties

# 3. تنظيف logs
rm -rf logs/*
mkdir -p logs

# 4. تفعيل السكريبتات
chmod +x scripts/*.sh

# 5. استعادة التبعيات
flutter pub get
```

**الوقت:** 10-15 دقيقة  
**الصعوبة:** سهل
