**إضافة تقرير جديد:**

## 6. المعايير المعتمدة

### أ. تسمية الملفات

**تقارير المهام:**

- `task_N_completion_report.md` - تقرير إكمال
- `TASK_N_SUMMARY.md` - ملخص المهمة

**ملخصات الجلسات:**

- `SESSION_SUMMARY_[TOPIC].md` - ملخص موضوع محدد
- `SESSION_SUMMARY.md` - ملخص عام

**تقارير الاختبار:**

- `[TYPE]_TESTING_REPORT.md` - تقرير اختبار
- `TESTING_SUMMARY.md` - ملخص الاختبارات

### ب. البنية الداخلية

**كل تقرير يجب أن يحتوي على:**

1. عنوان واضح
2. معلومات التعريف (تاريخ، مؤلف، حالة)
3. ملخص تنفيذي
4. محتوى مفصل
5. إحصائيات
6. توقيع

### ج. التحديث

**الفهرس:**

- يُحدث مع كل تقرير جديد
- يُراجع شهرياً
- يُنظف من الروابط المكسورة

**التقارير:**

- تُؤرشف بعد 3 أشهر
- تُحذف بعد سنة (إن لم تكن مهمة)
- تُحفظ النسخ الاحتياطية
