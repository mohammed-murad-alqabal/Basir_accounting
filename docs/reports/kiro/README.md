## 🛠️ أدوات إدارة التقارير

### **سكريبت إنشاء تقرير جديد:**

```bash
#!/bin/bash
# create_report.sh - إنشاء تقرير جديد

REPORT_TYPE=$1  # quality, cleanup, transformation, compliance
REPORT_NAME=$2
DATE=$(date +%Y-%m-%d)

mkdir -p .kiro/reports/$REPORT_TYPE
touch .kiro/reports/$REPORT_TYPE/${REPORT_NAME}_REPORT.md

echo "✅ تم إنشاء تقرير جديد: $REPORT_TYPE/${REPORT_NAME}_REPORT.md"
```

### **سكريبت أرشفة التقارير:**

```bash
#!/bin/bash
# archive_reports.sh - أرشفة التقارير القديمة

find .kiro/reports -name "*.md" -mtime +180 -exec mv {} .kiro/reports/archive/ \;
echo "✅ تم أرشفة التقارير الأقدم من 6 أشهر"
```
