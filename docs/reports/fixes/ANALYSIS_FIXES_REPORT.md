## 🎯 الحل المقترح لمشكلة الخط

### القرار الاستراتيجي (وكيل اتخاذ القرار)

```yaml
المشكلة: google_fonts يحتاج إنترنت لتحميل Cairo
الحل المقترح: استخدام خط Cairo محلي
الطريقة: إضافة Cairo كـ asset في pubspec.yaml
الفوائد:
  - لا يحتاج إنترنت
  - أسرع في التحميل
  - يعمل دائماً
  - حجم أصغر للتطبيق
```

### الخطوات المطلوبة:

#### 1. تحميل خط Cairo

```bash
# تحميل خط Cairo من Google Fonts
mkdir -p assets/fonts
cd assets/fonts
# تحميل الملفات:
# - Cairo-Regular.ttf
# - Cairo-Medium.ttf
# - Cairo-SemiBold.ttf
# - Cairo-Bold.ttf
```

#### 2. تحديث pubspec.yaml

```yaml
flutter:
  fonts:
    - family: Cairo
      fonts:
        - asset: assets/fonts/Cairo-Regular.ttf
          weight: 400
        - asset: assets/fonts/Cairo-Medium.ttf
          weight: 500
        - asset: assets/fonts/Cairo-SemiBold.ttf
          weight: 600
        - asset: assets/fonts/Cairo-Bold.ttf
          weight: 700
```

#### 3. تحديث lib/core/theme.dart

**قبل:**

```dart
import 'package:google_fonts/google_fonts.dart';

final textTheme = GoogleFonts.cairoTextTheme();
```

**بعد:**

```dart
final textTheme = const TextTheme(
  // استخدام Cairo المحلي
  bodyLarge: TextStyle(
    fontFamily: 'Cairo',
    fontSize: AppAppTypography.bodyLarge,
  ),
  // ... باقي الأنماط
);
```

#### 4. إزالة google_fonts من pubspec.yaml

```yaml
dependencies:
  # google_fonts: ^6.1.0  # إزالة
```
