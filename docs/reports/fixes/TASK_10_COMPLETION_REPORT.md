## الاختبار والتحقق

### اختبار القوالب

**الطريقة:**

1. الذهاب إلى صفحة Issues على GitHub
2. النقر على "New Issue"
3. التحقق من ظهور القوالب الثلاثة
4. اختيار كل قالب والتحقق من الحقول

**النتيجة المتوقعة:**

- ✅ ظهور 3 قوالب: Bug Report, Feature Request, Code Quality
- ✅ كل قالب يحتوي على جميع الحقول المطلوبة
- ✅ Labels تُضاف تلقائياً عند إنشاء Issue

### اختبار الـ Automated Label

**الطريقة:**

1. تشغيل GitHub Actions workflow
2. السماح للـ workflow بإنشاء Issue تلقائياً
3. التحقق من وجود label "automated"

**النتيجة المتوقعة:**

- ✅ Issue يُنشأ تلقائياً
- ✅ Label "automated" موجود
- ✅ Labels إضافية حسب نوع المشكلة
