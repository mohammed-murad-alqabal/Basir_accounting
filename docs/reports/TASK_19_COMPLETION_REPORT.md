### 2. نظام التخزين المؤقت ✅

**الملف:** `scripts/utils/cache_manager.sh`

**الإحصائيات:**

- عدد الأسطر: 300+
- عدد الدوال: 15+
- التغطية: شاملة
- دعم العربية: 100%

**المتطلبات:** Requirements 10.5

**الدوال الأساسية:**

#### أ. دوال التخزين الأساسية (6 دوال)

1. **cache_key** - توليد مفتاح كاش من نص

   ```bash
   key=$(cache_key "flutter_analyze")
   ```

2. **cache_exists** - التحقق من وجود كاش صالح

   ```bash
   if cache_exists "$key"; then
       echo "الكاش موجود"
   fi
   ```

3. **cache_get** - قراءة من الكاش

   ```bash
   result=$(cache_get "$key")
   ```

4. **cache_set** - الكتابة إلى الكاش

   ```bash
   cache_set "$key" "value"
   ```

5. **cache_delete** - حذف من الكاش

   ```bash
   cache_delete "$key"
   ```

6. **cache_clear** - مسح جميع الكاش
   ```bash
   cache_clear
   ```

#### ب. دوال الصيانة (2 دالة)

1. **cache_cleanup** - مسح الكاش المنتهي

   ```bash
   deleted=$(cache_cleanup)
   echo "تم حذف $deleted عنصر"
   ```

2. **cache_info** - عرض معلومات الكاش
   ```bash
   cache_info
   ```

#### ج. دوال القياس (2 دالة)

1. **cache_size** - حجم الكاش

   ```bash
   size=$(cache_size)
   ```

2. **cache_count** - عدد عناصر الكاش
   ```bash
   count=$(cache_count)
   ```

#### د. دوال مساعدة (1 دالة)

1. **cached_command** - تنفيذ أمر مع كاش
   ```bash
   result=$(cached_command "flutter analyze")
   ```

#### هـ. دوال خاصة بالمشروع (3 دوال)

1. **cache_flutter_analyze** - كاش نتائج التحليل

   ```bash
   result=$(cache_flutter_analyze)
   ```

2. **cache_flutter_test** - كاش نتائج الاختبارات

   ```bash
   result=$(cache_flutter_test)
   ```

3. **cache_file_list** - كاش قائمة الملفات
   ```bash
   files=$(cache_file_list "lib" "*.dart")
   ```

**الميزات:**

1. **صلاحية تلقائية:**

   - TTL قابل للتكوين (افتراضي: ساعة)
   - حذف تلقائي للكاش المنتهي
