## 📱 خطوات الاختبار

### 1. افتح التطبيق

التطبيق موجود على موبايلك (U693CL - Android 9)

### 2. اذهب إلى صفحة الاختبار

**الطريقة الأولى:**

- افتح التطبيق
- اذهب إلى Dashboard (الشاشة الرئيسية)
- ابحث عن زر "🧪 اختبار تحسينات واجهة المستخدم"
- اضغط عليه

**الطريقة الثانية:**

- إذا لم تجد الزر، أخبرني وسأساعدك

### 3. اختبر جميع المكونات

#### أ. الأزرار (AppButton)

**اختبر:**

- [ ] زر أساسي عادي - اضغط عليه
- [ ] زر أساسي مع أيقونة - اضغط عليه
- [ ] زر أساسي معطل - حاول الضغط (لن يعمل)
- [ ] زر أساسي في حالة تحميل - اضغط عليه
- [ ] زر ثانوي عادي - اضغط عليه
- [ ] زر ثانوي مع أيقونة - اضغط عليه
- [ ] زر ثانوي معطل - حاول الضغط (لن يعمل)
- [ ] زر ثانوي في حالة تحميل - اضغط عليه
- [ ] أزرار نصية (3 أزرار) - اضغط عليها

**تحقق من:**

- [ ] هل الضغط يعمل بشكل سلس؟
- [ ] هل تظهر حركة (ripple effect) عند الضغط؟
- [ ] هل الأزرار المعطلة واضحة؟
- [ ] هل حالة التحميل واضحة؟
- [ ] هل النصوص واضحة وقابلة للقراءة؟

---

#### ب. حقول الإدخال (AppTextField)

**اختبر:**

- [ ] حقل البريد الإلكتروني:
  - اكتب بريد صحيح (مثل: test@example.com)
  - اكتب بريد خاطئ (مثل: test)
  - اترك الحقل فارغاً واضغط "التحقق"
- [ ] حقل كلمة المرور:
  - اكتب كلمة مرور
  - اضغط على أيقونة العين (إظهار/إخفاء)
- [ ] حقل معطل:
  - حاول الكتابة فيه (لن يعمل)
- [ ] حقل الملاحظات:
  - اكتب نص طويل

**تحقق من:**

- [ ] هل الحدود واضحة عند التركيز؟
- [ ] هل رسائل الخطأ واضحة ومفيدة؟
- [ ] هل الكتابة سلسة؟
- [ ] هل إظهار/إخفاء كلمة المرور يعمل؟

---

#### ج. حقل البحث (AppSearchField)

**اختبر:**

- [ ] اكتب نص في حقل البحث
- [ ] اضغط على زر المسح (X)

**تحقق من:**

- [ ] هل زر المسح يظهر عند الكتابة؟
- [ ] هل المسح يعمل بشكل صحيح؟

---

#### د. زر التحقق

**اختبر:**

- [ ] اضغط على زر "التحقق من صحة النموذج"
- [ ] املأ الحقول بشكل صحيح واضغط مرة أخرى

**تحقق من:**

- [ ] هل تظهر رسائل الخطأ عند الحقول الفارغة؟
- [ ] هل تظهر رسالة نجاح عند الحقول الصحيحة؟

---
