### 9.4 سكريبت مراقبة الأداء

#### المسار: scripts/monitor_performance.sh

```bash
#!/bin/bash

echo "📊 مراقبة أداء النظام..."
echo "================================"

# CPU Usage
echo "🔥 استخدام CPU:"
top -bn1 | grep "Cpu(s)" | awk '{print "  " $2 " user, " $4 " system"}'

# Memory Usage
echo ""
echo "💾 استخدام الذاكرة:"
free -h | grep "Mem:" | awk '{print "  المستخدم: " $3 " / " $2 " (" int($3/$2*100) "%)"}'

# Disk Usage
echo ""
echo "💿 استخدام القرص:"
df -h . | tail -1 | awk '{print "  المستخدم: " $3 " / " $2 " (" $5 ")"}'

# Load Average
echo ""
echo "⚡ Load Average:"
uptime | awk -F'load average:' '{print "  " $2}'

# Top Processes
echo ""
echo "🔝 أكثر 5 عمليات استهلاكاً للـ CPU:"
ps aux --sort=-%cpu | head -6 | tail -5 | awk '{printf "  %s: %.1f%% CPU, %.1f%% MEM\n", $11, $3, $4}'

# Project Size
echo ""
echo "📦 حجم المشروع:"
du -sh . 2>/dev/null | awk '{print "  الإجمالي: " $1}'
du -sh build 2>/dev/null | awk '{print "  build: " $1}'

echo ""
echo "================================"
```

**الاستخدام:**

```bash
chmod +x scripts/monitor_performance.sh
./scripts/monitor_performance.sh
```
