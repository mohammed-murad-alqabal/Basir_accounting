## 🎓 الميزات الاحترافية

### 1. Conventional Commits

```

fix(scope): وصف الإصلاح
docs(scope): وصف التوثيق
test(scope): وصف الاختبار
chore(scope): وصف المهمة
```

### 2. الفحوصات التلقائية

- التنسيق (dart format)
- التحليل (flutter analyze)
- الاختبارات (flutter test)

