## 🔄 المرحلة 2: اختبار شاشة العملاء (قيد التنفيذ)

### الهدف

اختبار جميع الوظائف الجديدة في شاشة العملاء:

- إضافة عميل جديد
- عرض تفاصيل عميل
- تعديل بيانات عميل
- حذف عميل

### الخطوات التفصيلية

#### 1. الانتقال إلى شاشة العملاء

**الإجراء:**

- النقر على أيقونة "العملاء" في BottomNavigationBar
- أو النقر على زر "عميل جديد" في Dashboard

**المتوقع:**

- الانتقال إلى شاشة قائمة العملاء
- عرض العملاء الموجودين (إن وجدوا)
- ظهور زر "+" في الأعلى

**الاختبار:**

- [ ] الانتقال يعمل بسلاسة
- [ ] الشاشة تظهر بشكل صحيح
- [ ] RTL يعمل بشكل صحيح
- [ ] زر "+" موجود وواضح

#### 2. إضافة عميل جديد

**الإجراء:**

- النقر على زر "+"
- ملء النموذج:
  - الاسم: "أحمد محمد علي"
  - البريد: "ahmed@example.com"
  - الهاتف: "0501234567"
  - العنوان: "الرياض، المملكة العربية السعودية"
  - الملاحظات: "عميل مهم"
- النقر على زر "حفظ"

**المتوقع:**

- فتح شاشة النموذج
- جميع الحقول تظهر بشكل صحيح
- Validation يعمل:
  - الاسم مطلوب
  - البريد يجب أن يكون صحيح (regex)
  - الهاتف يجب أن يبدأ بـ 05 ويتكون من 10 أرقام
- رسالة نجاح بعد الحفظ
- العودة إلى قائمة العملاء
- العميل الجديد يظهر في القائمة

**الاختبار:**

- [ ] النموذج يفتح بشكل صحيح
- [ ] جميع الحقول موجودة
- [ ] Validation للاسم يعمل
- [ ] Validation للبريد يعمل
- [ ] Validation للهاتف يعمل
- [ ] زر الحفظ يعمل
- [ ] رسالة النجاح تظهر
- [ ] العودة التلقائية تعمل
- [ ] العميل يظهر في القائمة

#### 3. عرض تفاصيل عميل

**الإجراء:**

- النقر على العميل المضاف حديثاً

**المتوقع:**

- فتح شاشة تفاصيل العميل
- عرض جميع المعلومات:
  - صورة دائرية بالحرف الأول
  - الاسم
  - البريد
  - الهاتف
  - العنوان
  - الملاحظات
  - تاريخ الإضافة
  - تاريخ التحديث
- أزرار التعديل والحذف في AppBar

**الاختبار:**

- [ ] الشاشة تفتح بشكل صحيح
- [ ] جميع المعلومات تظهر
- [ ] الصورة الدائرية تظهر
- [ ] التواريخ صحيحة
- [ ] أزرار التعديل والحذف موجودة
- [ ] التصميم احترافي

#### 4. تعديل بيانات عميل

**الإجراء:**

- من شاشة التفاصيل، النقر على زر التعديل
- تعديل الاسم إلى: "أحمد محمد علي السعيد"
- تعديل الملاحظات إلى: "عميل مهم جداً - VIP"
- النقر على زر "حفظ"

**المتوقع:**

- فتح نفس النموذج مع البيانات الحالية
- إمكانية تعديل أي حقل
- Validation يعمل
- رسالة نجاح بعد الحفظ
- العودة إلى شاشة التفاصيل
- البيانات المحدثة تظهر
- تاريخ التحديث يتغير

**الاختبار:**

- [ ] النموذج يفتح مع البيانات الحالية
- [ ] التعديل يعمل
- [ ] Validation يعمل
- [ ] زر الحفظ يعمل
- [ ] رسالة النجاح تظهر
- [ ] البيانات المحدثة تظهر
- [ ] تاريخ التحديث صحيح

#### 5. حذف عميل

**الإجراء:**

- من شاشة التفاصيل، النقر على زر الحذف
- تأكيد الحذف في الحوار

**المتوقع:**

- ظهور حوار تأكيد
- رسالة واضحة: "هل أنت متأكد من حذف هذا العميل؟"
- زرين: "حذف" و "إلغاء"
- بعد التأكيد:
  - رسالة نجاح
  - العودة إلى قائمة العملاء
  - العميل لا يظهر في القائمة

**الاختبار:**

- [ ] حوار التأكيد يظهر
- [ ] الرسالة واضحة
- [ ] زر الإلغاء يعمل
- [ ] زر الحذف يعمل
- [ ] رسالة النجاح تظهر
- [ ] العودة التلقائية تعمل
- [ ] العميل تم حذفه فعلاً
