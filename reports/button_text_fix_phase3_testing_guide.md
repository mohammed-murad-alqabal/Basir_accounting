## 🧪 الاختبارات المطلوبة

### الاختبار 1: textScaleFactor المختلفة ⭐⭐⭐

**الهدف:** التأكد من عدم قص النص مع جميع قيم textScaleFactor

**الخطوات:**

1. انتقل لتبويب **"اختبار تفاعلي"**
2. استخدم الـ slider لتغيير textScaleFactor
3. اختبر القيم التالية:

| القيمة   | الوصف        | النتيجة المتوقعة | ✅/❌ |
| -------- | ------------ | ---------------- | ----- |
| **0.8x** | نص صغير      | عرض كامل بدون قص |       |
| **1.0x** | نص عادي      | عرض كامل بدون قص |       |
| **1.3x** | نص كبير      | عرض كامل بدون قص |       |
| **1.5x** | نص كبير جداً | عرض كامل بدون قص |       |
| **2.0x** | نص ضخم       | عرض كامل بدون قص |       |

**معايير النجاح:**

- ✅ لا يوجد قص أفقي أو عمودي
- ✅ جميع النصوص مقروءة
- ✅ الأزرار تحافظ على شكلها

### الاختبار 2: النصوص الطويلة ⭐⭐⭐

**الهدف:** اختبار الأزرار مع نصوص طويلة جداً

**الخطوات:**

1. انتقل لتبويب **"سيناريوهات متطرفة"**
2. اختبر الأزرار التالية:

| الزر             | النص                     | النتيجة المتوقعة           | ✅/❌ |
| ---------------- | ------------------------ | -------------------------- | ----- |
| **نص طويل جداً** | "هذا نص طويل جداً..."    | عرض متعدد الأسطر           |       |
| **نص مع أيقونة** | "نص طويل مع أيقونة..."   | أيقونة + نص متعدد الأسطر   |       |
| **حجم صغير**     | "نص طويل مع حجم صغير..." | عرض متعدد الأسطر بحجم صغير |       |

**معايير النجاح:**

- ✅ النص يلتف لأسطر متعددة
- ✅ لا يوجد قص أو اختفاء
- ✅ الأيقونات تظهر بشكل صحيح

### الاختبار 3: أنماط الأزرار المختلفة ⭐⭐

**الهدف:** اختبار جميع أنماط الأزرار

**الخطوات:**

1. في تبويب **"اختبار تفاعلي"**
2. اختبر الأنماط التالية:

| النمط         | الوصف         | النتيجة المتوقعة        | ✅/❌ |
| ------------- | ------------- | ----------------------- | ----- |
| **Primary**   | زر أساسي أزرق | خلفية زرقاء، نص أبيض    |       |
| **Secondary** | زر ثانوي      | خلفية ثانوية، نص مناسب  |       |
| **Outlined**  | زر بحدود      | حدود ملونة، خلفية شفافة |       |
| **Text**      | زر نصي        | بدون خلفية، نص ملون     |       |

**معايير النجاح:**

- ✅ جميع الأنماط تظهر بشكل صحيح
- ✅ الألوان متباينة ومقروءة
- ✅ لا يوجد قص في أي نمط

### الاختبار 4: أحجام الأزرار ⭐⭐

**الهدف:** اختبار جميع أحجام الأزرار

**الخطوات:**

1. في تبويب **"اختبار تفاعلي"** - قسم "أحجام مختلفة"
2. اختبر الأحجام التالية:

| الحجم      | الوصف     | النتيجة المتوقعة     | ✅/❌ |
| ---------- | --------- | -------------------- | ----- |
| **Small**  | حجم صغير  | ارتفاع 36px، خط 14px |       |
| **Medium** | حجم متوسط | ارتفاع 48px، خط 16px |       |
| **Large**  | حجم كبير  | ارتفاع 56px، خط 18px |       |

**معايير النجاح:**

- ✅ الأحجام متناسقة ومناسبة
- ✅ النصوص مقروءة في جميع الأحجام
- ✅ لا يوجد قص في أي حجم

### الاختبار 5: الحالات الخاصة ⭐⭐

**الهدف:** اختبار الحالات الخاصة للأزرار

**الخطوات:**

1. في تبويب **"سيناريوهات متطرفة"** - قسم "حالات خاصة"
2. اختبر الحالات التالية:

| الحالة       | الوصف            | النتيجة المتوقعة              | ✅/❌ |
| ------------ | ---------------- | ----------------------------- | ----- |
| **Loading**  | زر في حالة تحميل | مؤشر دوار + "جاري التحميل..." |       |
| **Disabled** | زر معطل          | لون باهت، غير قابل للضغط      |       |
| **Tooltip**  | زر مع tooltip    | tooltip يظهر عند الضغط المطول |       |

**معايير النجاح:**

- ✅ حالة التحميل واضحة
- ✅ الزر المعطل واضح
- ✅ Tooltip يعمل بشكل صحيح

### الاختبار 6: دعم RTL ⭐⭐

**الهدف:** اختبار دعم اللغة العربية والتخطيط من اليمين لليسار

**الخطوات:**

1. في تبويب **"سيناريوهات متطرفة"** - قسم "اختبار RTL"
2. اختبر النصوص التالية:

| النوع           | النص                       | النتيجة المتوقعة          | ✅/❌ |
| --------------- | -------------------------- | ------------------------- | ----- |
| **إنجليزي**     | "English Text Button"      | محاذاة مناسبة             |       |
| **مختلط**       | "نص عربي مختلط مع English" | محاذاة صحيحة للنص المختلط |       |
| **أرقام عربية** | "١٢٣٤٥ أرقام عربية مع نص"  | عرض صحيح للأرقام العربية  |       |

**معايير النجاح:**

- ✅ النصوص العربية محاذاة لليمين
- ✅ النصوص الإنجليزية محاذاة مناسبة
- ✅ النصوص المختلطة تعرض بشكل صحيح

### الاختبار 7: اختبار الأداء ⭐

**الهدف:** اختبار أداء الأزرار تحت الضغط

**الخطوات:**

1. انتقل لتبويب **"اختبار الأداء"**
2. اضغط على **"تشغيل اختبار 50 زر"**
3. اضغط على **"اختبار الضغط (100 زر)"**

**معايير النجاح:**

- ✅ التطبيق لا يتجمد
- ✅ جميع الأزرار تعرض بشكل صحيح
- ✅ لا توجد تحذيرات overflow
- ✅ الأداء سلس (60fps)

**كيفية المراقبة:**

1. راقب console في Android Studio/VS Code
2. ابحث عن رسائل مثل:
   ```
   RenderFlex overflowed by X pixels on the right.
   ```

**الإجراء عند الاكتشاف:**

- ✅ سجل النص الذي سبب المشكلة
- ✅ سجل قيمة textScaleFactor
- ✅ التقط screenshot
- ✅ سجل في تقرير النتائج
