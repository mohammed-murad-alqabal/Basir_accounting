**التأثير:**

- 🟡 **متوسط** - التطبيق يعمل بدون المشاكل
- 🟡 VS Code يعمل بشكل ممتاز كبديل
- 🟡 تحسين تجربة التطوير في Android Studio

**خطوات التثبيت اليدوية:**

#### الطريقة 1: من داخل Android Studio (موصى بها)

1. فتح Android Studio
2. File → Settings (أو Ctrl+Alt+S)
3. Plugins
4. Marketplace
5. البحث عن "Flutter"
6. تثبيت Flutter Plugin
7. سيتم تثبيت Dart Plugin تلقائياً
8. إعادة تشغيل Android Studio

#### الطريقة 2: من سطر الأوامر (متقدمة)

```bash
# الانتقال إلى مجلد Plugins
cd ~/.local/share/JetBrains/AndroidStudio2025.1/plugins

# تحميل Flutter Plugin
# ملاحظة: يجب تحميل من Marketplace يدوياً
# الرابط: https://plugins.jetbrains.com/plugin/9212-flutter
```

**ملاحظة هامة:** التثبيت من داخل Android Studio أسهل وأكثر أماناً.

**الأولوية:** 🟡 **متوسطة** - اختياري لكن موصى به
