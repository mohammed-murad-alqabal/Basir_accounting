### خطوات التثبيت اليدوية

#### الطريقة 1: من داخل Android Studio

1. فتح Android Studio
2. File → Settings (أو Ctrl+Alt+S)
3. Plugins
4. Marketplace
5. البحث عن "Flutter"
6. تثبيت Flutter Plugin
7. سيتم تثبيت Dart Plugin تلقائياً
8. إعادة تشغيل Android Studio

#### الطريقة 2: من سطر الأوامر

```bash
# تحميل Plugins
cd ~/.local/share/JetBrains/AndroidStudio2025.1/plugins

# Flutter Plugin
wget https://plugins.jetbrains.com/plugin/download?pluginId=9212

# Dart Plugin
wget https://plugins.jetbrains.com/plugin/download?pluginId=6351

# إعادة تشغيل Android Studio
```

**ملاحظة:** التثبيت من داخل Android Studio أسهل وأكثر أماناً.
