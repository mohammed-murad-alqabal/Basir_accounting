## 10. خطة الإعداد الموصى بها

### 10.1 الإجراءات الفورية (الآن) 🔴

#### أ. إعداد Git

```bash
# ضبط معلومات المستخدم
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# التحقق
git config --global user.name
git config --global user.email
```

**الأولوية:** 🔴 عالية جداً  
**الوقت المتوقع:** 1 دقيقة  
**التأثير:** ضروري للـ commits

#### ب. إعداد متغيرات البيئة

```bash
# إضافة إلى ~/.bashrc أو ~/.zshrc
cat >> ~/.bashrc << 'EOF'

# Android SDK
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/tools
export PATH=$PATH:$ANDROID_HOME/tools/bin
export PATH=$PATH:$ANDROID_HOME/platform-tools

# Java (من Android Studio)
export JAVA_HOME=/snap/android-studio/209/jbr
export PATH=$PATH:$JAVA_HOME/bin

# Flutter
export PATH=$PATH:$HOME/flutter/bin
EOF

# تطبيق التغييرات
source ~/.bashrc
```

**الأولوية:** 🟡 متوسطة  
**الوقت المتوقع:** 2 دقيقة  
**التأثير:** يحسن التوافقية

### 10.2 التحسينات الموصى بها (قريباً) 🟡

#### أ. تثبيت GitHub CLI

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install gh

# التحقق
gh --version

# تسجيل الدخول
gh auth login
```

**الأولوية:** 🟡 متوسطة  
**الوقت المتوقع:** 5 دقائق  
**الفائدة:** إدارة أسهل لـ GitHub

#### ب. تثبيت Android Studio Plugins

1. فتح Android Studio
2. File → Settings → Plugins
3. تثبيت:
   - Flutter Plugin
   - Dart Plugin

**الأولوية:** 🟡 متوسطة  
**الوقت المتوقع:** 5 دقائق  
**الفائدة:** تطوير أفضل في Android Studio

### 10.3 التحسينات الاختيارية (لاحقاً) 🟢

#### أ. تثبيت yq

```bash
# Ubuntu/Debian
sudo apt install yq

# أو باستخدام snap
sudo snap install yq
```

**الأولوية:** 🟢 منخفضة  
**الوقت المتوقع:** 2 دقيقة  
**الفائدة:** معالجة ملفات YAML

#### ب. تحديث التبعيات

```bash
# مراجعة التحديثات المتاحة
flutter pub outdated

# تحديث (اختياري)
flutter pub upgrade
```

**الأولوية:** 🟢 منخفضة  
**الوقت المتوقع:** 10 دقائق  
**الفائدة:** أحدث الميزات
