## 6. Feedback Loop

### Feedback Collection

| Method           | Frequency  | Purpose          |
| ---------------- | ---------- | ---------------- |
| In-app feedback  | Continuous | Quick sentiment  |
| NPS Survey       | Quarterly  | Loyalty tracking |
| User interviews  | Monthly    | Deep insights    |
| Feature requests | Continuous | Product roadmap  |
| App reviews      | Continuous | Public feedback  |

### Feature Prioritization

Using RICE scoring:

- **R**each: How many users affected?
- **I**mpact: How much improvement?
- **C**onfidence: How sure are we?
- **E**ffort: How much work?
