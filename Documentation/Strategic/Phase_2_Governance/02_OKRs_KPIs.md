## OKR Framework

We use the **Objectives and Key Results (OKR)** framework for strategic goal-setting:

- **Objectives**: Qualitative, inspirational goals
- **Key Results**: Quantitative, measurable outcomes
- **Cadence**: Quarterly OKRs with annual goals

## KPI Dashboard

### North Star Metric

> **Monthly Active Invoices Created**

### Growth Metrics

| KPI        | Definition            | Target   | Frequency |
| ---------- | --------------------- | -------- | --------- |
| MAU        | Monthly active users  | Growth   | Monthly   |
| Signups    | New registrations     | 10%/week | Weekly    |
| Activation | First invoice created | 60%      | Weekly    |
| Conversion | Free to paid          | 10%      | Monthly   |

### Revenue Metrics

| KPI  | Definition                | Target | Frequency |
| ---- | ------------------------- | ------ | --------- |
| MRR  | Monthly recurring revenue | Growth | Monthly   |
| ARR  | Annual recurring revenue  | $1M Y1 | Quarterly |
| ARPU | Avg revenue per user      | $30/mo | Monthly   |
| LTV  | Lifetime value            | $720   | Quarterly |

### Retention Metrics

| KPI           | Definition           | Target | Frequency |
| ------------- | -------------------- | ------ | --------- |
| D1 Retention  | Day 1 return rate    | > 50%  | Daily     |
| D7 Retention  | Week 1 return rate   | > 40%  | Weekly    |
| D30 Retention | Month 1 return rate  | > 30%  | Monthly   |
| Churn         | Monthly cancellation | < 5%   | Monthly   |

### Product Metrics

| KPI        | Definition            | Target | Frequency |
| ---------- | --------------------- | ------ | --------- |
| NPS        | Net Promoter Score    | > 50   | Quarterly |
| CSAT       | Customer satisfaction | > 90%  | Monthly   |
| Crash Rate | App crashes/session   | < 0.1% | Daily     |
| Load Time  | App startup time      | < 2s   | Daily     |

### Operational Metrics

| KPI              | Definition          | Target  | Frequency |
| ---------------- | ------------------- | ------- | --------- |
| Support Response | First response time | < 4hrs  | Daily     |
| Resolution Time  | Ticket close time   | < 24hrs | Daily     |
| Uptime           | System availability | > 99.9% | Daily     |
| Deployment Freq  | Releases per week   | 2+      | Weekly    |
