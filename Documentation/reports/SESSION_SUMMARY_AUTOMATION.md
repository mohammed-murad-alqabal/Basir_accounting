**السيناريوهات المدعومة:**

1. استهلاك CPU عالي → cleanup.sh
2. استهلاك ذاكرة عالي → flutter clean
3. مساحة قرص منخفضة → تنظيف شامل
4. فشل البناء → clean + rebuild
5. مشاكل التبعيات → pub cache repair
6. فشل الاختبارات → تحليل وإبلاغ
7. تغطية منخفضة → توصيات
8. مشاكل التحليل → dart fix --apply
9. ثغرات أمنية → flutter pub upgrade
10. حجم مشروع كبير → cleanup.sh
11. ذاكرة مؤقتة تالفة → إعادة بناء
