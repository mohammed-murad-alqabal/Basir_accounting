## الميزات الرئيسية

### 1. معالجة أخطاء موحدة

**قبل:**

```bash
if ! command; then
    echo "Error" >&2
    exit 1
fi
```

**بعد:**

```bash
if ! command; then
    handle_command_error "command" $? "فشل التنفيذ"
fi
```

### 2. تسجيل شامل

**قبل:**

```bash
echo "Error: something failed" >&2
```

**بعد:**

```bash
log_error "فشل تنفيذ العملية: $operation"
log_info "اقتراح: تحقق من الصلاحيات"
```

### 3. استرداد تلقائي

**قبل:**

```bash
curl -f "$url" || exit 1
```

**بعد:**

```bash
retry_command 3 2 "curl -f $url" || {
    log_error "فشل التحميل بعد 3 محاولات"
    exit 1
}
```

### 4. نسخ احتياطي آمن

**قبل:**

```bash
# تعديل مباشر بدون نسخة احتياطية
echo "new_data" > important_file
```

**بعد:**

```bash
# نسخة احتياطية قبل التعديل
backup_file "important_file" "backups"
echo "new_data" > important_file
```

### 5. تحقق استباقي

**قبل:**

```bash
# تنفيذ مباشر بدون تحقق
flutter analyze
```

**بعد:**

```bash
# تحقق من المتطلبات أولاً
check_command "flutter" || exit 1
check_disk_space 100 "." || exit 1
flutter analyze
```

## حالات الاستخدام

### حالة 1: سكريبت بسيط

```bash
#!/bin/bash
source "$(dirname "$0")/utils/error_handler.sh"

print_info "بدء العملية..."
check_command "flutter" || exit 1

if flutter analyze; then
    print_success "التحليل نجح!"
else
    log_error "فشل التحليل"
    exit 1
fi
```

### حالة 2: سكريبت مع إعادة المحاولة

```bash
#!/bin/bash
source "$(dirname "$0")/utils/error_handler.sh"

print_info "تحميل البيانات..."

if retry_command 5 3 "curl -f $url"; then
    print_success "تم التحميل"
else
    log_error "فشل التحميل بعد 5 محاولات"
    exit 1
fi
```

### حالة 3: سكريبت مع نسخ احتياطي

```bash
#!/bin/bash
source "$(dirname "$0")/utils/error_handler.sh"

CONFIG="config.yml"

backup_file "$CONFIG" "backups" || exit 1

if ! update_config "$CONFIG"; then
    log_error "فشل التحديث - استعادة النسخة"
    BACKUP=$(ls -t backups/config.yml.backup.* | head -1)
    restore_backup "$BACKUP" "$CONFIG"
    exit 1
fi

print_success "تم التحديث بنجاح"
```
