## الخيارات المتاحة

### 1. --keep-logs

**الوصف:** الحفاظ على السجلات (لا حذف)

**الاستخدام:**

```bash
bash scripts/uninstall.sh --keep-logs
```

**الفائدة:**

- الحفاظ على السجلات للمراجعة
- عدم فقدان البيانات المهمة
- إمكانية إعادة التثبيت مع الاحتفاظ بالسجلات

### 2. --keep-config

**الوصف:** الحفاظ على ملفات التكوين

**الاستخدام:**

```bash
bash scripts/uninstall.sh --keep-config
```

**الفائدة:**

- الحفاظ على التكوين المخصص
- سهولة إعادة التثبيت بنفس الإعدادات
- عدم فقدان التخصيصات

### 3. --force

**الوصف:** إلغاء التثبيت بدون تأكيد

**الاستخدام:**

```bash
bash scripts/uninstall.sh --force
```

**الفائدة:**

- إلغاء تثبيت تلقائي
- مفيد في السكريبتات الآلية
- توفير الوقت

### 4. --verbose

**الوصف:** عرض تفاصيل إضافية أثناء الإلغاء

**الاستخدام:**

```bash
bash scripts/uninstall.sh --verbose
```

**الفائدة:**

- تتبع دقيق لعملية الإلغاء
- تشخيص المشاكل
- معلومات تفصيلية

### 5. -h, --help

**الوصف:** عرض رسالة المساعدة

**الاستخدام:**

```bash
bash scripts/uninstall.sh --help
```
