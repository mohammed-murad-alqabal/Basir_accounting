## 📋 الخطوة الوحيدة المطلوبة

### 1. افتح المتصفح

**انسخ هذا الرابط والصقه في المتصفح:**

```
https://github.com/mohammed-murad-alqabal/Basser_MVP/settings/branches
```

### 2. غير الفرع الافتراضي

**ستجد:**

```
┌─────────────────────────────────────────┐
│ Default branch                          │
├─────────────────────────────────────────┤
│ The default branch is main              │
│                                         │
│ [main] [⇄]  ← اضغط على السهمين         │
└─────────────────────────────────────────┘
```

**الإجراء:**

1. اضغط على أيقونة **⇄** (السهمين)
2. ستظهر قائمة منسدلة
3. اختر **master**
4. اضغط **Update**
5. سيظهر تحذير، اضغط **I understand, update the default branch**

### 3. تأكيد النجاح

**يجب أن ترى:**

```
┌─────────────────────────────────────────┐
│ Default branch                          │
├─────────────────────────────────────────┤
│ The default branch is master ✅         │
│                                         │
│ [master] [⇄]                            │
└─────────────────────────────────────────┘
```
