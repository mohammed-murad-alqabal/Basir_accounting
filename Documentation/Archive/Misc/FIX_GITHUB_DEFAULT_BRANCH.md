# دليل تغيير الفرع الافتراضي على GitHub

**المشكلة:** لا يمكن حذف `main` لأنه الفرع الافتراضي  
**الحل:** تغيير الفرع الافتراضي إلى `master` أولاً

---

## 🎯 الخطوات (5 دقائق)

### الخطوة 1: افتح إعدادات المستودع

1. اذهب إلى: https://github.com/mohammed-murad-alqabal/Basser_MVP
2. اضغط على **Settings** (في الأعلى)
3. اضغط على **Branches** (في القائمة اليسرى)

### الخطوة 2: غير الفرع الافتراضي

1. في قسم **Default branch**، ستجد:

   ```
   The default branch is main
   ```

2. اضغط على أيقونة **⇄** (السهمين) بجانب `main`

3. في القائمة المنسدلة، اختر **master**

4. اضغط على **Update**

5. سيظهر تحذير، اضغط على **I understand, update the default branch**

### الخطوة 3: تأكيد التغيير

ستظهر رسالة:

```
✅ Default branch changed to master
```


## ⚠️ ملاحظات مهمة

### لماذا يجب تغيير الفرع الافتراضي أولاً؟

GitHub يحمي الفرع الافتراضي من الحذف لمنع فقدان البيانات.

### ماذا لو لم أستطع الوصول إلى Settings؟

تحتاج إلى صلاحيات **Admin** على المستودع.

### هل سيؤثر هذا على أي شيء؟

لا! التغيير آمن تماماً:

- ✅ لن يؤثر على الكود
- ✅ لن يؤثر على التاريخ
- ✅ لن يؤثر على Pull Requests
- ✅ فقط يغير الفرع الذي يفتح افتراضياً
