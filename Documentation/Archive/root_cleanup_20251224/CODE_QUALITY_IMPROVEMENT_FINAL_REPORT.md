1. **Dynamic Type Casting Errors (6 أخطاء)**

   - إصلاح `metrics['failedTests'] > 0` → `(metrics['failedTests'] as int? ?? 0) > 0`
   - إصلاح `metrics['successRate']` → `metrics['successRate'] as double? ?? 0.0`
   - إصلاح جميع dynamic type accesses

2. **Non-Bool Operand Errors (3 أخطاء)**

   - إصلاح `failuresByType['golden'] > 0` → `(failuresByType['golden'] as int? ?? 0) > 0`
   - إصلاح جميع boolean conditions

3. **Argument Type Errors (6 أخطاء)**
   - إصلاح `failure['type']` → `failure['type'] as String? ?? 'unknown'`
   - إصلاح جميع string parameters

#### الحل المطبق:

```dart

}
```
