## 1. المشاكل الحرجة (Critical Issues)

### 1.1 RenderFlex Overflow في app_card.dart

**الموقع:** `lib/core/widgets/app_card.dart:255`  
**الخطورة:** 🔴 حرجة  
**الوصف:** تجاوز 32 بكسل على اليمين في Row widget

**السبب:**

- النص في label قد يكون طويلاً
- عدم استخدام Expanded أو Flexible
- المساحة المتاحة محدودة (64 بكسل فقط)

**الحل المطبق:**

```dart
// قبل الإصلاح
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Text(label, ...),
    Icon(icon, ...),
  ],
)

// بعد الإصلاح
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  children: [
    Expanded(
      child: Text(
        label,
        overflow: TextOverflow.ellipsis,
        ...
      ),
    ),
    const SizedBox(width: AppSpacing.sm),
    Icon(icon, ...),
  ],
)
```

**الحالة:** ✅ تم الإصلاح

## 4. التوصيات العامة

### 4.1 تحسينات الأداء

**الأولوية:** عالية

1. **استخدام const constructors:**

   - البحث عن جميع الـ widgets الثابتة
   - إضافة const حيثما أمكن

2. **تحسين بناء الـ widgets:**

   - تقسيم الـ widgets الكبيرة
   - استخدام const للـ widgets المتكررة

3. **Lazy Loading:**
   - تحميل البيانات عند الحاجة فقط
   - استخدام pagination للقوائم الطويلة

### 4.2 إصلاح Overflow Issues

**الأولوية:** حرجة

1. **فحص جميع Row widgets:**

   - التأكد من استخدام Expanded/Flexible
   - إضافة overflow handling للنصوص

2. **فحص جميع Column widgets:**

   - التأكد من عدم تجاوز الارتفاع
   - استخدام SingleChildScrollView عند الحاجة

3. **اختبار على شاشات مختلفة:**
   - شاشات صغيرة
   - شاشات كبيرة
   - اتجاهات مختلفة

### 4.3 تحسين تجربة المستخدم
