**الأولوية:** 🔥 حرجة

**الخطوات:**

```bash
# 1. إنشاء keystore

  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias basser-key-alias

# 2. إنشاء key.properties
echo "storePassword=<password>" > android/key.properties
echo "keyPassword=<password>" >> android/key.properties
echo "keyAlias=basser-key-alias" >> android/key.properties
echo "storeFile=basser-release-key.jks" >> android/key.properties

# 3. تحديث build.gradle
```
