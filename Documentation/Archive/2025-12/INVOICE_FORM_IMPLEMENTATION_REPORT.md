## 🔧 التغييرات المنفذة

### 1. إنشاء InvoiceFormScreen ✅

**الملف:** `lib/features/invoices/presentation/screens/invoice_form_screen.dart`

#### الميزات المنفذة:

##### أ. اختيار العميل

- قائمة منسدلة (Dropdown) لاختيار العميل من قائمة العملاء الموجودين
- التحقق من اختيار العميل (إلزامي)
- عرض أسماء العملاء بشكل واضح

##### ب. تواريخ الفاتورة

- **تاريخ الإصدار:** قابل للتعديل عبر Date Picker
- **تاريخ الاستحقاق:** قابل للتعديل عبر Date Picker
- القيمة الافتراضية: تاريخ الاستحقاق = تاريخ الإصدار + 30 يوم

##### ج. نسبة الضريبة

- عرض نسبة الضريبة الحالية (15% افتراضياً)
- إمكانية تعديل النسبة عبر نافذة حوار
- التحقق من صحة النسبة (0-100%)

##### د. حالة الفاتورة

- قائمة منسدلة لاختيار الحالة:
  - مسودة (draft)
  - مرسلة (issued)
  - مدفوعة (paid)
  - متأخرة (overdue)
  - ملغاة (cancelled)

##### هـ. إدارة البنود

- **إضافة بند:** نافذة حوار لإدخال:
  - اسم المنتج/الخدمة
  - الكمية
  - السعر
- **عرض البنود:** قائمة بجميع البنود مع:
  - الاسم
  - الكمية × السعر
  - الإجمالي
- **حذف بند:** زر حذف لكل بند
- **التحقق:** يجب إضافة بند واحد على الأقل

##### و. حساب الإجماليات

- **المجموع الفرعي:** مجموع جميع البنود
- **الضريبة:** المجموع الفرعي × نسبة الضريبة
- **الإجمالي الكلي:** المجموع الفرعي + الضريبة
- **التحديث التلقائي:** عند إضافة/حذف بنود أو تغيير الضريبة

##### ز. ملاحظات

- حقل نصي متعدد الأسطر (اختياري)
- لإضافة ملاحظات أو شروط خاصة

##### ح. الحفظ والتحقق

- **التحقق من البيانات:**
  - اختيار العميل (إلزامي)
  - وجود بند واحد على الأقل (إلزامي)
  - صحة جميع الحقول
- **حالة التحميل:** عرض مؤشر تحميل أثناء الحفظ
- **رسائل النجاح/الخطأ:** واضحة ومفيدة

#### الكود المنفذ:


```dart
Future<void> _addInvoice() async {
  final result = await Navigator.push<bool>(
    context,
    MaterialPageRoute(
      builder: (context) => const InvoiceFormScreen(),
    ),
  );

  if (result ?? false) {
    ref.invalidate(invoicesProvider);
  }
}

Future<void> _editInvoice(Invoice invoice) async {
  final result = await Navigator.push<bool>(
    context,
    MaterialPageRoute(
      builder: (context) => InvoiceFormScreen(invoice: invoice),
    ),
  );

  if (result ?? false) {
    ref.invalidate(invoicesProvider);
  }
}
```
