### 3. مشاكل الواجهة (UI Issues)

#### المشكلة: Overflow في بطاقات الإحصائيات

**الأعراض:**

- `BOTTOM OVERFLOWED BY 35 PIXELS`
- `BOTTOM OVERFLOWED BY 27 PIXELS`
- `BOTTOM OVERFLOWED BY 25 PIXELS`
- النصوص مقطوعة: "المبيعا..." بدلاً من "المبيعات"
- الأرقام مقطوعة: "5,24..." بدلاً من الرقم الكامل

#### الحلول المطبقة:

**1. إعادة تصميم AppStatCard:**

```dart
// قبل:
- Layout أفقي (Row)
- padding: EdgeInsets.all(AppSpacing.md)
- fontSize: 12 للنص
- fontSize: 20 للقيمة

// بعد:
- Layout عمودي (Column) مع محاذاة مركزية
- padding: EdgeInsets.symmetric(horizontal: sm, vertical: md)
- fontSize: 11 للنص
- fontSize: 22 للقيمة مع FittedBox
- Icon size: 28
```

**2. تعديل GridView:**

```dart
// قبل:
childAspectRatio: 1.4

// بعد:
childAspectRatio: 1.3
```

**3. استخدام FittedBox:**

```dart
FittedBox(
  fit: BoxFit.scaleDown,
  child: Text(value, ...),
)
```
