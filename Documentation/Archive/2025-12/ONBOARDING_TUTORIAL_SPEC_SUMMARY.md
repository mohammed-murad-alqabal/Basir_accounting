## ✨ الميزات الرئيسية

### 1. عرض تلقائي عند أول استخدام

- التعليمات تظهر تلقائياً لكل شاشة عند أول زيارة
- نظام ذكي لتتبع الشاشات المعروضة

### 2. تحكم كامل

- **التالي:** الانتقال للنصيحة التالية
- **السابق:** العودة للنصيحة السابقة
- **تخطي:** إغلاق التعليمات الحالية
- **عدم الإظهار مرة أخرى:** إخفاء نهائي

### 3. إعادة العرض

- خيار في الإعدادات لإعادة عرض جميع التعليمات
- زر مساعدة (؟) في كل شاشة

### 4. تصميم احترافي

- Overlay شبه شفاف
- تسليط الضوء على العنصر المستهدف
- بطاقة نصيحة جميلة
- حركات انتقالية سلسة

## 🔄 تدفق المستخدم

### أول استخدام

```
1. المستخدم يفتح التطبيق
2. تظهر التعليمات تلقائياً
3. المستخدم يتنقل بين النصائح
4. عند الانتهاء: رسالة "رائع! الآن أنت جاهز"
5. يتم حفظ الحالة
```

### تخطي التعليمات

```
1. المستخدم ينقر "تخطي"
2. يظهر حوار تأكيد
3. خيارات:
   - نعم، تخطي
   - لا، متابعة
   - عدم الإظهار مرة أخرى
```

### إعادة العرض

```
1. المستخدم يذهب للإعدادات
2. ينقر "إعادة عرض التعليمات"
3. حوار تأكيد
4. إعادة تعيين جميع التعليمات
5. رسالة نجاح
```
