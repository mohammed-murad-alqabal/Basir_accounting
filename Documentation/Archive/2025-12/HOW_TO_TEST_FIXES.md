## 🔄 خطوات إعادة التشغيل

### الطريقة 1: إعادة تشغيل كاملة (موصى بها)

```bash
# 1. إيقاف التطبيق الحالي
# اضغط Ctrl+C في Terminal

# 2. إعادة التشغيل
flutter run
```

### الطريقة 2: Hot Restart (أسرع)

في Android Studio أو VS Code:

- اضغط `Shift + R` (Hot Restart)
- أو اضغط على أيقونة ⚡ مع السهم الدائري

**ملاحظة:** Hot Reload (R فقط) **لن يكفي** لأن التغييرات في:

- `main.dart` (تهيئة التطبيق)
- `providers.dart` (Riverpod providers)

## 🧪 خطوات الاختبار الكاملة

### 1. إعادة تشغيل التطبيق

```bash
# في Terminal
flutter run
```

انتظر حتى يظهر:

```
✓ Built build/app/outputs/flutter-apk/app-debug.apk
```

### 2. اختبار شاشة تسجيل الدخول

- [ ] تحقق من وضوح نص "تسجيل الدخول"
- [ ] تحقق من وضوح نص "الدخول كضيف"
- [ ] تحقق من وضوح نص "أنشئ حساباً الآن"

### 3. تسجيل الدخول

```
اسم المستخدم: أي نص
كلمة المرور: أي نص
```

### 4. اختبار شاشة الفواتير

- [ ] انتقل إلى شاشة الفواتير
- [ ] تحقق من أزرار الفلتر:
  - ✅ "الكل"
  - ✅ "مدفوعة"
  - ✅ "مرسلة"
  - ✅ "متأخرة"
- [ ] تحقق من **عدم ظهور** خطأ Isar
- [ ] جرب الضغط على أزرار الفلتر

### 5. اختبار شاشة العملاء

- [ ] انتقل إلى شاشة العملاء
- [ ] تحقق من تحميل البيانات بدون أخطاء

## 🐛 إذا استمرت المشاكل

### المشكلة: لا تزال أزرار الفلتر بالإنجليزية

**الحل:**

```bash
# 1. تنظيف البناء
flutter clean

# 2. إعادة البناء
flutter pub get

# 3. إعادة التشغيل
flutter run
```

### المشكلة: خطأ Isar لا يزال موجوداً

**الحل:**

```bash
# 1. إلغاء تثبيت التطبيق من الجهاز
adb uninstall com.example.basser_app

# 2. إعادة التثبيت
flutter run
```

### المشكلة: نصوص الأزرار غير واضحة

**السبب المحتمل:** مشكلة في الخط أو حجم الخط

**الحل:** سأقوم بفحص ملف `app_button.dart` وتحسينه

## 💡 نصائح مهمة

1. **دائماً استخدم Hot Restart** (⚡ + 🔄) وليس Hot Reload عند:

   - تغيير `main.dart`
   - تغيير Providers
   - تغيير Models
   - إضافة dependencies جديدة

2. **استخدم `flutter clean`** إذا:

   - استمرت المشاكل بعد إعادة التشغيل
   - ظهرت أخطاء غريبة
   - تم تحديث dependencies

3. **تحقق من logs** في Terminal:
   ```bash
   flutter run --verbose
   ```
