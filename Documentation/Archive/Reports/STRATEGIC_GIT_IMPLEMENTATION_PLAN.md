### المرحلة 2: الدمج الآمن (التنفيذ القادم)

#### الخطوة 1: دمج main في master

```bash
# 1. التأكد من النظافة
git checkout master
git status

# 2. جلب آخر التحديثات
git fetch origin

# 3. دمج main في master (لضمان عدم فقدان أي شيء)
git merge origin/main --no-ff -m "merge: integrate main updates into master"

# 4. حل أي تعارضات (إن وجدت)
# يدوياً إذا لزم الأمر

# 5. دفع master المحدث
git push origin master
```

#### الخطوة 2: تحديث main ليطابق master

```bash
# 1. الانتقال إلى main
git checkout main

# 2. إعادة تعيين main ليطابق master تماماً
git reset --hard origin/master

# 3. دفع التحديثات (force push مع حماية)
git push origin main --force-with-lease
```

#### الخطوة 3: تغيير الفرع الافتراضي

**على GitHub:**

1. Settings → Branches
2. Default branch → اختر `main`
3. Update

### المرحلة 3: التنظيف والتوثيق

```bash
# 1. حذف master البعيد (بعد التأكد من نجاح كل شيء)
git push origin --delete master

# 2. حذف master المحلي
git branch -D master

# 3. تنظيف المراجع
git fetch --all --prune
git remote prune origin

# 4. التحقق النهائي
git branch -a
git status
```
