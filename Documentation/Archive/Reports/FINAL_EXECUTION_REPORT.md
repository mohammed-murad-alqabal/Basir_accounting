### على GitHub (يدوياً)

1. **تغيير الفرع الافتراضي:**

   - Settings → Branches
   - Default branch → اختر `main`
   - Update

2. **حذف master (اختياري):**
   - Settings → Branches
   - ابحث عن `master`
   - Delete branch

### محلياً (اختياري)

