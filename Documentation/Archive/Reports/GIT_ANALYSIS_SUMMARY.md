## 🆘 الأمان

### النسخ الاحتياطية

السكريبت ينشئ نسخ احتياطية تلقائياً:

```bash
backup-master-YYYYMMDD-HHMMSS  # نسخة من master
backup-main-YYYYMMDD-HHMMSS    # نسخة من main (إن وجد)
```

### الاستعادة

إذا حدث أي خطأ:

```bash
# عرض النسخ الاحتياطية
git branch -a | grep backup

# استعادة master
git checkout backup-master-YYYYMMDD
git branch -D master
git checkout -b master
git push -f origin master
```
