# دليل اختبار المرحلة 3 على Android

**المشروع:** بصير MVP  
**التاريخ:** 5 ديسمبر 2025  
**المؤلف:** فريق وكلاء تطوير مشروع بصير  
**المرحلة:** 3 - المهمة 3 (اختبار Android)  
**الجهاز:** U693CL (Android 9 - API 28)  
**الحالة:** 📋 جاهز للتنفيذ

---

## 🎯 الهدف

اختبار شامل لـ `AppEnhancedButton` على جهاز Android حقيقي للتحقق من:

- عدم وجود قص للنصوص (أفقي أو عمودي)
- التكيف الصحيح مع textScaleFactor (1.0x - 2.0x)
- عدم وجود RenderFlex overflow
- الاتساق في جميع الحالات

---

## 📱 الإعداد

### الخطوة 1: توصيل الجهاز

```bash
# 1. توصيل الجهاز بالكمبيوتر عبر USB
# 2. تفعيل USB Debugging على الجهاز
# 3. التحقق من الاتصال
adb devices
```

**النتيجة المتوقعة:**

```
List of devices attached
<device-id>    device
```

### الخطوة 2: بناء التطبيق

```bash
# بناء APK للاختبار (debug mode)
flutter build apk --debug

# أو للاختبار الأسرع
flutter run -d <device-id>
```

**ملاحظة:** استخدم `flutter run` للاختبار السريع مع hot reload.

### الخطوة 3: الوصول لشاشة الاختبار

1. افتح التطبيق على الجهاز
2. سجل الدخول أو استخدم وضع الضيف
3. في شاشة Dashboard، اضغط على أيقونة 🐛 (Bug) في الأعلى
4. ستفتح شاشة "اختبار الأزرار"

## 🚨 المشاكل المحتملة والحلول

### مشكلة 1: RenderFlex overflow

**الأعراض:** رسالة خطأ صفراء وسوداء على الشاشة

**الحل:**

1. سجل تفاصيل المشكلة (أي زر، أي textScaleFactor)
2. التقط screenshot
3. سنصلحها في المرحلة 4

### مشكلة 2: قص النص

**الأعراض:** النص يختفي جزئياً أو كلياً

**الحل:**

1. سجل تفاصيل المشكلة بدقة
2. التقط screenshot
3. جرب textScaleFactor مختلفة
4. سنصلحها فوراً

### مشكلة 3: الأداء البطيء

**الأعراض:** تأخير عند تغيير textScaleFactor

**الحل:**

1. تحقق من معدل الإطارات في DevTools
2. سجل الملاحظات
3. سنحسن الأداء إذا لزم الأمر
