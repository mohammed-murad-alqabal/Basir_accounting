AppFontMetrics

AppFontMetrics class

نظام مقاييس الخطوط لضمان عرض النصوص بشكل صحيح بدون قص.

يوفر هذا النظام حسابات دقيقة لارتفاع الخطوط والـ padding المطلوب لضمان عدم قص النصوص في جميع الحالات، خاصة مع خط Cairo العربي.

مثال:

final metrics = AppFontMetrics.forFont('Cairo', 16.0);
final requiredHeight = metrics.calculateRequiredHeight(
  textScaleFactor: 1.5,
);
