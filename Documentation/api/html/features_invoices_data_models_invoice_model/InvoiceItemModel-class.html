نموذج بند الفاتورة (Invoice Item Model)

نموذج Isar مضمن (Embedded) لتخزين بنود الفاتورة. يتم تخزينه كجزء من InvoiceModel وليس كمجموعة منفصلة.

مثال:

final itemModel = InvoiceItemModel()
  ..id = 'item-1'
  ..name = 'خدمة استشارية'
  ..quantity = 2.0
  ..price = 500.0;
