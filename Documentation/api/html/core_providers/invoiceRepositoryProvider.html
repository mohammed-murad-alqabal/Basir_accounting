invoiceRepositoryProvider top-level property

Provider<InvoiceRepository> invoiceRepositoryProvider
final

مزود مستودع الفواتير (Invoice Repository)

يوفر وصولاً إلى عمليات CRUD للفواتير:

  • إنشاء فاتورة جديدة
  • تحديث حالة الفاتورة
  • حذف فاتورة
  • البحث والاستعلام عن الفواتير
  • تصدير الفواتير كـ PDF

Example:

final repository = ref.watch(invoiceRepositoryProvider);
final invoices = await repository.getAllInvoices();

Implementation

final invoiceRepositoryProvider = Provider<InvoiceRepository>((ref) {
  final isar = ref.watch(isarProvider).value;
  if (isar == null) {
    throw Exception('قاعدة البيانات غير جاهزة');
  }
  return InvoiceRepositoryImpl(isar: isar);
});
