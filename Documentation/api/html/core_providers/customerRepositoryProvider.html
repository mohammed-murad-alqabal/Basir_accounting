customerRepositoryProvider top-level property

Provider<CustomerRepository> customerRepositoryProvider
final

مزود مستودع العملاء (Customer Repository)

يوفر وصولاً إلى عمليات CRUD للعملاء:

  • إضافة عميل جديد
  • تحديث بيانات عميل
  • حذف عميل
  • البحث والاستعلام عن العملاء

Example:

final repository = ref.watch(customerRepositoryProvider);
final customers = await repository.getAllCustomers();

Implementation

final customerRepositoryProvider = Provider<CustomerRepository>((ref) {
  final isar = ref.watch(isarProvider).value;
  if (isar == null) {
    throw Exception('قاعدة البيانات غير جاهزة');
  }
  return CustomerRepositoryImpl(isar: isar);
});
