FontManager

FontManager class

مدير الخطوط مع دعم fallback آمن.

يدير تحميل الخطوط والتحقق من توفرها، ويوفر خطوط fallback آمنة في حالة فشل تحميل الخط الأساسي.

مثال:

await FontManager.initialize();
final fontFamily = FontManager.getPrimaryFont();
