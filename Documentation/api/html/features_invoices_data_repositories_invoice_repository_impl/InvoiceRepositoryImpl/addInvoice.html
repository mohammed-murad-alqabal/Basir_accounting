إضافة فاتورة جديدة

يضيف فاتورة جديدة إلى النظام.

Parameters:

  • invoice: بيانات الفاتورة الجديدة

Throws: Exception إذا حدث خطأ في الحفظ

مثال:

final invoice = Invoice(...);
await repository.addInvoice(invoice);

Implementation

@override
Future<void> addInvoice(Invoice invoice) async {
  try {
    final model = InvoiceModel.fromEntity(invoice);
    await isar.writeTxn(() async {
      await isar.invoiceModels.put(model);
    });
  } catch (e) {
    throw Exception('خطأ في إضافة الفاتورة: $e');
  }
}
