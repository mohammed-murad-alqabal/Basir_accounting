### المرحلة 2: التحسينات الإضافية (قصيرة المدى)

#### 2.1 إضافة خوادم MCP إضافية

**الأولوية:** 🟡 متوسطة  
**الوقت المتوقع:** 30-60 دقيقة

**الخوادم المقترحة:**

##### أ. خادم SQLite (لقاعدة البيانات المحلية)

```json
{
  "sqlite": {
    "command": "uvx",
    "args": ["mcp-server-sqlite@latest"],
    "disabled": false,
    "autoApprove": ["query", "execute"],
    "priority": 80
  }
}
```

**الفائدة:** التعامل مع قواعد بيانات Isar/SQLite مباشرة

##### ب. خادم Time (للوقت والتاريخ)

```json
{
  "time": {
    "command": "uvx",
    "args": ["mcp-server-time@latest"],
    "disabled": false,
    "autoApprove": ["get_time", "convert_timezone"],
    "priority": 75
  }
}
```

**الفائدة:** عمليات الوقت والتاريخ (مهم للفواتير)

##### ج. خادم AWS Git Research (بحث متقدم)

```json
{
  "git-research": {
    "command": "uvx",
    "args": ["awslabs.git-repo-research-mcp-server@latest"],
    "disabled": false,
    "autoApprove": ["search_code", "analyze_repo"],
    "priority": 70
  }
}
```

**الفائدة:** بحث وتحليل متقدم في الكود

#### 2.2 تحسين التكوين

**الأولوية:** 🟢 منخفضة  
**الوقت المتوقع:** 15-30 دقيقة

**التحسينات المقترحة:**

1. إضافة timeout للخوادم
2. تحسين مستويات logging
3. إضافة retry logic
4. توثيق autoApprove لكل خادم
