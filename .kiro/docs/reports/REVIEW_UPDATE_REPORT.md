```json
  "enabled": true,
  "version": "2.0",
  "trigger": {
    "type": "onSessionStart"
  },
  "action": {
    "type": "askAgent",

}
```

**التحسينات:**

- ✅ تحديث البنية لتتوافق مع النمط الجديد
