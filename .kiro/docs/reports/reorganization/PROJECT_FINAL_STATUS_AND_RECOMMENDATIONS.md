## 🎯 التوصيات للمتابعة

### 1. أرشفة docs/Archive/ (أولوية متوسطة)

**المشكلة:**

- مجلد Archive/ قد يحتوي على ملفات قديمة جداً
- يساهم في حجم docs/ الكبير (20MB)

**الحل المقترح:**

```bash
# فحص محتوى Archive/
find docs/Archive -type f -mtime +90

# أرشفة الملفات القديمة (أكثر من 90 يوم)
tar -czf docs/archive_$(date +%Y%m%d).tar.gz \
  docs/Archive/

# نقل الأرشيف
mv docs/archive_*.tar.gz .kiro/archives/
```

**الفوائد:**

- تقليل حجم docs/
- الحفاظ على الملفات القديمة
- تحسين الأداء

**الهدف:** منع تراكم التقارير القديمة

**الخطة:**

- مراجعة شهرية لـ `.kiro/docs/reports/`

#!/bin/bash

### 3. إنشاء hooks للوقاية (أولوية عالية)

**الهدف:** منع تراكم الملفات في الجذر مستقبلاً

**Hook مقترح:**

```bash
#!/bin/bash
# .githooks/pre-commit

# التحقق من عدم إضافة ملفات غير مرغوبة في الجذر
UNWANTED_FILES=$(git diff --cached --name-only | grep -E '^[^/]+\.(log|tmp|bak)$')

if [ -n "$UNWANTED_FILES" ]; then
  echo "❌ خطأ: محاولة إضافة ملفات غير مرغوبة في الجذر:"
  echo "$UNWANTED_FILES"
  echo ""
  echo "الرجاء نقل هذه الملفات إلى المجلدات المناسبة:"
  echo "  - *.log → logs/"
  echo "  - *.tmp → /tmp/"
  echo "  - *.bak → backups/"
  exit 1
fi
```

### 5. مراقبة الحجم (أولوية منخفضة)

**الهدف:** منع نمو المشروع بشكل غير مسيطر عليه

**السكريبت المقترح:**

```bash
#!/bin/bash
# scripts/maintenance/check_size.sh

echo "=== حجم المجلدات الرئيسية ==="
du -sh Documentation .kiro/docs scripts logs

# تحذير إذا تجاوز docs/ 25MB
SIZE=$(du -sm Documentation | cut -f1)
if [ $SIZE -gt 25 ]; then
  echo "⚠️ تحذير: docs/ تجاوز 25MB ($SIZE MB)"
  echo "الرجاء مراجعة وأرشفة الملفات القديمة"
fi
```
