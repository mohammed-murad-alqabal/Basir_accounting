## 🔧 التكوين

### التفعيل

```bash
# تكوين Git لاستخدام .githooks
git config core.hooksPath .githooks

# جعل الـ hooks قابلة للتنفيذ
chmod +x .githooks/pre-commit .githooks/pre-push

# التحقق من التكوين
git config core.hooksPath
# Output: .githooks
```

### التحقق من التثبيت

```bash
# اختبار pre-commit
./.githooks/pre-commit

# اختبار pre-push
```
