## 2. قواعد الكتابة

### 2.1 علامات الترقيم

#### القواعد

- استخدام الفاصلة العربية (،) وليس الإنجليزية (,)
- استخدام علامة الاستفهام العربية (؟) وليس الإنجليزية (?)
- استخدام الفاصلة المنقوطة (؛) بشكل صحيح
- استخدام النقطة (.) في نهاية الجمل

#### أمثلة صحيحة ✅

```dart
'هل تريد حذف هذا العميل؟'
'تم حفظ البيانات بنجاح.'
'يرجى إدخال: الاسم، رقم الهاتف، والعنوان.'
```

#### أمثلة خاطئة ❌

```dart
'هل تريد حذف هذا العميل?'  // علامة استفهام إنجليزية
'تم حفظ البيانات بنجاح'  // بدون نقطة
'يرجى إدخال: الاسم, رقم الهاتف, والعنوان'  // فاصلة إنجليزية
```

### 2.2 الأرقام

#### القواعد

- استخدام الأرقام العربية (١٢٣) أو الهندية (123) بشكل متسق
- **الموصى به:** الأرقام الهندية (123) لسهولة القراءة
- استخدام الفاصلة (،) لفصل الآلاف
- استخدام النقطة (.) للكسور العشرية

#### أمثلة صحيحة ✅

```dart
'المبلغ: 1,500 ريال'
'الضريبة: 15%'
'الإجمالي: 1,725.00 ريال'
```

#### أمثلة خاطئة ❌

```dart
'المبلغ: 1500 ريال'  // بدون فاصلة
'الضريبة: ١٥%'  // خلط بين الأرقام
'الإجمالي: 1.725,00 ريال'  // فاصلة ونقطة معكوسة
```

### 2.3 التواريخ

#### القواعد

- استخدام التنسيق: يوم/شهر/سنة
- كتابة أسماء الأشهر بالعربية
- استخدام التقويم الهجري والميلادي حسب الحاجة

#### أمثلة صحيحة ✅

```dart
'29 نوفمبر 2025'
'29/11/2025'
'الخميس، 29 نوفمبر 2025'
```

#### أمثلة خاطئة ❌

```dart
'2025/11/29'  // تنسيق أمريكي
'Nov 29, 2025'  // إنجليزي
'29-11-2025'  // شرطات بدلاً من شرطات مائلة
```

## 3. رسائل المستخدم

### 3.1 رسائل التأكيد

#### القواعد

- واضحة ومباشرة
- تشرح الإجراء والنتيجة
- تطلب تأكيد صريح

#### أمثلة صحيحة ✅

```dart
'هل أنت متأكد من حذف هذا العميل؟'
'سيتم حذف جميع الفواتير المرتبطة بهذا العميل. هل تريد المتابعة؟'
'هل تريد حفظ التغييرات قبل الخروج؟'
```

#### أمثلة خاطئة ❌

```dart
'حذف؟'  // غير واضح
'متأكد؟'  // غير مفصل
'Delete customer?'  // إنجليزي
```

### 3.2 رسائل الخطأ

#### القواعد

- تشرح المشكلة بوضوح
- تقدم حل أو إرشاد
- لا تلوم المستخدم

#### أمثلة صحيحة ✅

```dart
'رقم الهاتف يجب أن يبدأ بـ 05 ويتكون من 10 أرقام.'
'البريد الإلكتروني غير صحيح. يرجى التحقق من الصيغة.'
'لا يمكن حذف هذا العميل لأنه مرتبط بفواتير موجودة.'
'حدث خطأ أثناء حفظ البيانات. يرجى المحاولة مرة أخرى.'
```

#### أمثلة خاطئة ❌

```dart
'خطأ!'  // غير مفيد
'رقم خاطئ'  // غير واضح
'أنت أدخلت بيانات خاطئة'  // يلوم المستخدم
'Error: Invalid input'  // إنجليزي
```

### 3.3 رسائل النجاح

#### القواعد

- إيجابية ومشجعة
- تؤكد الإجراء المكتمل
- واضحة ومحددة

```dart

'تم حفظ الفاتورة بنجاح.'
'تم تصدير الفاتورة كملف PDF بنجاح.'

## 5. التوثيق والتعليقات

### 5.1 DartDoc بالعربية

#### القواعد

- استخدام العربية الفصحى
- شرح واضح ومفصل
- أمثلة عملية

#### مثال صحيح ✅

````dart
/// يمثل عميل في النظام.
///
/// يحتوي على جميع المعلومات الأساسية للعميل بما في ذلك
/// الاسم، رقم الهاتف، والعنوان. يتم استخدام هذا الكلاس
/// في جميع عمليات إدارة العملاء.
///
/// مثال:
/// ```dart
/// final customer = Customer(
///   id: 'customer-1',
///   name: 'أحمد محمد',
///   phone: '0501234567',
///   email: 'ahmed@example.com',
/// );
/// ```
class Customer {
  /// معرف فريد للعميل.
  ///
  /// يتم توليده تلقائياً عند إنشاء عميل جديد.
  final String id;

  /// اسم العميل الكامل.
  ///
  /// يجب أن يكون غير فارغ ويحتوي على حرفين على الأقل.
  final String name;
}
````

### 5.2 التعليقات الداخلية

#### القواعد

- واضحة ومفيدة
- تشرح "لماذا" وليس "ماذا"
- بالعربية للمنطق المعقد

#### مثال صحيح ✅

```dart
// نستخدم regex للتحقق من صحة البريد الإلكتروني
// لأن الصيغة البسيطة لا تغطي جميع الحالات
final emailRegex = RegExp(r'^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$');

// نقوم بحساب الضريبة بناءً على النسبة المحددة في الإعدادات
// إذا لم تكن محددة، نستخدم القيمة الافتراضية 15%
final taxRate = settings.taxRate ?? 0.15;
```

#### مثال خاطئ ❌

```dart

### مثال 1: شاشة قائمة العملاء

```dart
class CustomersScreen extends StatelessWidget {
  const CustomersScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('قائمة العملاء'),
        actions: [
          IconButton(
            icon: const Icon(Icons.search),
            tooltip: 'بحث عن عميل',
            onPressed: () {
              // فتح شاشة البحث
            },
          ),
        ],
      ),
      body: Consumer(
        builder: (context, ref, child) {
          final customersAsync = ref.watch(customersProvider);

          return customersAsync.when(
            data: (customers) {
              if (customers.isEmpty) {
                return const Center(
                  child: Text('لا يوجد عملاء. اضغط + لإضافة عميل جديد'),
                );
              }
              return ListView.builder(
                itemCount: customers.length,
                itemBuilder: (context, index) {
                  final customer = customers[index];
                  return CustomerCard(customer: customer);
                },
              );
            },
            loading: () => const Center(
              child: CircularProgressIndicator(),
            ),
            error: (error, stack) => Center(
              child: Text('حدث خطأ أثناء تحميل العملاء: $error'),
            ),
          );
        },
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () {
          // فتح شاشة إضافة عميل
        },
        tooltip: 'إضافة عميل جديد',
        child: const Icon(Icons.add),
      ),
    );
  }
}
```

### مثال 2: رسائل التحقق

```dart
class CustomerValidator {
  /// يتحقق من صحة اسم العميل.
  ///
  /// Returns رسالة خطأ إذا كان الاسم غير صحيح، أو null إذا كان صحيحاً.
  static String? validateName(String? value) {
    if (value == null || value.isEmpty) {
      return 'اسم العميل مطلوب';
    }
    if (value.length < 2) {
      return 'اسم العميل يجب أن يحتوي على حرفين على الأقل';
    }
    if (value.length > 100) {
      return 'اسم العميل طويل جداً (الحد الأقصى 100 حرف)';
    }
    return null;
  }

  /// يتحقق من صحة رقم الهاتف.
  ///
  /// Returns رسالة خطأ إذا كان الرقم غير صحيح، أو null إذا كان صحيحاً.
  static String? validatePhone(String? value) {
    if (value == null || value.isEmpty) {
      return 'رقم الهاتف مطلوب';
    }
    if (!value.startsWith('05')) {
      return 'رقم الهاتف يجب أن يبدأ بـ 05';
    }
    if (value.length != 10) {
      return 'رقم الهاتف يجب أن يتكون من 10 أرقام';
    }
    if (!RegExp(r'^[0-9]+$').hasMatch(value)) {
      return 'رقم الهاتف يجب أن يحتوي على أرقام فقط';
    }
    return null;
  }
}
```
