## نظرة عامة

هذا المجلد يحتوي على تعريفات وإعدادات **فريق الوكلاء المطورين** الذين يعملون معاً على تطوير مشروع بصير. كل وكيل متخصص في مجال محدد ويتعاون مع الوكلاء الآخرين لتحقيق أهداف المشروع.

## الوكلاء المتاحون

### 1. وكيل اتخاذ القرار (Decision Agent)

**الدور:** اتخاذ القرارات الاستراتيجية والتقنية  
**المسؤوليات:**

- تحليل المتطلبات وتحديد الأولويات
- اختيار التقنيات والأدوات المناسبة
- حل النزاعات التقنية
- الموافقة على التغييرات الكبيرة

### 2. وكيل التطوير (Development Agent)

**الدور:** كتابة وتنفيذ الكود  
**المسؤوليات:**

- تنفيذ المهام من specs/tasks.md
- كتابة كود نظيف ومختبر
- اتباع معايير الجودة
- إصلاح الأخطاء

### 3. وكيل التحليل (Analysis Agent)

**الدور:** تحليل الكود والأداء والجودة  
**المسؤوليات:**

- تشغيل flutter analyze
- تحليل تغطية الاختبارات
- مراقبة الأداء
- اكتشاف المشاكل المحتملة

### 4. وكيل الإدارة (Management Agent)

**الدور:** إدارة المشروع والتنسيق بين الوكلاء  
**المسؤوليات:**

- تتبع تقدم المهام
- تحديث الوثائق
- إدارة الجدول الزمني
- التواصل مع المستخدم

### 5. وكيل الاختبار (Testing Agent)

**الدور:** ضمان جودة الكود من خلال الاختبارات  
**المسؤوليات:**

- كتابة Unit Tests
- كتابة Widget Tests
- كتابة Integration Tests
- تشغيل الاختبارات والتحقق من النتائج

### 6. وكيل الأمان (Security Agent)

**الدور:** ضمان أمان التطبيق والبيانات  
**المسؤوليات:**

- مراجعة الكود للثغرات الأمنية
- التحقق من تشفير البيانات الحساسة
- فحص التبعيات للثغرات
- تطبيق best practices الأمنية

### 7. وكيل التوثيق (Documentation Agent)

**الدور:** توثيق الكود والمشروع  
**المسؤوليات:**

- كتابة DartDoc للكود
- تحديث README.md
- تحديث CHANGELOG.md
- إنشاء أدلة المستخدم

### 8. وكيل المراجعة (Review Agent)

**الدور:** مراجعة الكود قبل الدمج  
**المسؤوليات:**

- مراجعة Pull Requests
- التحقق من اتباع المعايير
- اقتراح تحسينات
- الموافقة على التغييرات

## سير العمل

### دورة التطوير الكاملة

1. **التخطيط:** وكيل الإدارة + وكيل اتخاذ القرار
2. **التطوير:** وكيل التطوير + وكيل الاختبار
3. **الجودة:** وكيل التحليل + وكيل الأمان
4. **التوثيق:** وكيل التوثيق
5. **المراجعة:** وكيل المراجعة
6. **الإكمال:** وكيل الإدارة
