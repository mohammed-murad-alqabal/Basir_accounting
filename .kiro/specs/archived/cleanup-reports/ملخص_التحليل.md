## 🚨 ملاحظات مهمة

### النسخة الاحتياطية

السكريبت ينشئ نسخة احتياطية تلقائياً:

```
.kiro/specs/backup-YYYYMMDD-HHMMSS/
```

إذا حدث خطأ، استعد بـ:

```bash
BACKUP=$(ls -1dt .kiro/specs/backup-* | head -1)
rm -rf .kiro/specs/active .kiro/specs/completed .kiro/specs/archived
cp -r $BACKUP/* .kiro/specs/
```

### لا فقدان للبيانات

السكريبت فقط **ينقل** الملفات، لا يحذفها أبداً. كل شيء محفوظ
في مجلدات archived/.

