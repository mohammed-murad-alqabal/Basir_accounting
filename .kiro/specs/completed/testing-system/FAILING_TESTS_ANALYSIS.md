## تصنيف الاختبارات الفاشلة

### 1. اختبارات Router (22 اختبار فاشل) 🔴

**الملف:** `test/unit/core/router_test.dart`

**المشكلة الرئيسية:**

```
StateError: Bad state: No element
```

**السبب:**

- اختبارات Router تحاول الوصول إلى elements غير موجودة
- المشكلة في `WidgetController.element` - لا يوجد widget مطابق
- Router tests تم إنشاؤها حديثاً ولم يتم اختبارها بشكل صحيح

**الاختبارات المتأثرة:**

- `should generate route for /`
- `should generate route for /login`
- `should generate route for /dashboard`
- `should generate route for /customers`
- `should generate route for /invoices`
- `should generate route for /settings`
- `should generate route for /setup`
- وغيرها... (22 اختبار إجمالي)

**الأولوية:** 🔴 حرجة جداً

**الحل المقترح:**

1. مراجعة بنية اختبارات Router
2. استخدام `MaterialApp` بشكل صحيح
3. التأكد من وجود widgets قبل الوصول إليها
4. استخدام `pumpAndSettle()` بعد navigation

### 2. اختبار CI/CD Integration (1 اختبار فاشل) 🟡

**الملف:** `test/integration/ci_cd_integration_test.dart`

**المشكلة:**

```
Expected: true

```

**الاختبار المتأثر:**

- `should generate coverage report`

**السبب:**

- ملف `coverage/lcov.info` غير موجود أو فارغ

**الأولوية:** 🟡 متوسطة

**الحل المقترح:**

1. تشغيل `flutter test --coverage` قبل الاختبار
2. أو تعديل الاختبار ليكون أكثر مرونة
3. أو skip هذا الاختبار مؤقتاً
