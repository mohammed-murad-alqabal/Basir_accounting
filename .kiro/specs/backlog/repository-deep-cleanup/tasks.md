# خطة تحسين وصيانة المستودع (Repository Maintenance Plan)

## نظرة عامة

خطة مبسطة وعملية لتنظيف المستودع وتحقيق النتائج المثالية بأقل وقت ممكن. التركيز على النتائج الفورية باستخدام الأدوات الموجودة.

## الأهداف المستهدفة

- **توفير المساحة**: 18-20MB (من 25.86MB إلى ~6MB)
- **تحسين الأداء**: 25%+ تسريع في عمليات Git
- **تقليل الملفات**: من 500+ إلى 350 ملف
- **وقت التنفيذ**: 90 دقيقة بدلاً من أسبوع

## المهام المبسطة

### 1. تنظيف مجلد السجلات (logs/) - 30 دقيقة

- [x] 1.1 إنشاء هيكل المشروع والمكونات الأساسية

  - استخدام الأدوات الموجودة في `tools/repository_cleaner/`
  - _المتطلبات: 1.1, 2.1, 3.1_

- [x] 1.2 تنظيف logs/ مباشرة وبساطة
  - حذف الملفات الأقدم من 30 يوم باستخدام find command
  - ضغط السجلات المهمة (آخر 7 أيام) في أرشيف واحد
  - حذف ملفات الاختبار المؤقتة (42+ ملف) من logs/archive/
  - إنشاء تقرير بسيط بالملفات المحذوفة
  - _المتطلبات: 1.1, 1.2, 1.3_

### 2. تنظيف التوثيق (docs/) - 20 دقيقة

- [x] 2.1 إنشاء محرك التنظيف الذكي الرئيسي

  - استخدام الأدوات الموجودة
  - _المتطلبات: 1.2, 1.3, 1.4_

- [x] 2.2 تنظيف docs/reports/ بكفاءة
  - حذف التقارير المكررة والقديمة (> 60 يوم)
  - ضغط docs/Archive/ الموجود
  - دمج التقارير المتشابهة بصريًا
  - _المتطلبات: 3.1, 3.2, 3.4_

### 3. تنظيف النسخ الاحتياطية والملفات المؤقتة - 25 دقيقة

- [x] 3.1 تطوير نظام الأرشفة الذكية المتقدم

  - استخدام الأدوات الموجودة
  - _المتطلبات: 3.2, 3.3_

- [x] 3.2 تنظيف .dependency_backups/ بسرعة

  - الاحتفاظ بآخر 3 نسخ فقط
  - حذف النسخ الأقدم من 14 يوم
  - _المتطلبات: 2.1, 2.2, 2.3_

- [x] 3.3 تنظيف الملفات المؤقتة المتناثرة
  - البحث وحذف ملفات .tmp, .log, .bak
  - تنظيف build/ cache
  - تنظيف .dart_tool/ cache (الحفاظ على التكوينات المهمة)
  - _المتطلبات: 4.1, 4.2_

### 4. تحسين Git وإنشاء التقرير - 15 دقيقة

- [x] 4.1 تطوير نظام الأمان متعدد المستويات

  - استخدام الأدوات الموجودة
  - _المتطلبات: 6.4, 6.5_

- [x] 4.2 تحسين أداء Git بسرعة

  - تشغيل git prune (Safe usage)
  - حذف .git/lost-found (1.7GB saved)
  - تحديث .gitignore لمنع الملفات المؤقتة مستقبلاً
  - _المتطلبات: 7.1, 7.2_

- [x] 4.3 إنشاء تقرير التنظيف البسيط
  - توثيق الملفات المحذوفة والمساحة الموفرة
  - حساب تحسن الأداء
  - حفظ التقرير في docs/reports/cleanup/
  - _المتطلبات: 8.1, 8.2_

## ملاحظات التنفيذ

- **البساطة والفعالية**: كل مهمة تحقق نتائج فورية وملموسة
- **الأمان**: إنشاء نسخة احتياطية قبل أي حذف
- **السرعة**: 90 دقيقة إجمالي بدلاً من أسبوع كامل
